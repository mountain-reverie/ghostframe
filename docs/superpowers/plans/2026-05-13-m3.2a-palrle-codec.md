# M3.2a PalRLE Codec + Palette Table Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the PalRLE tile codec end-to-end — server-side GPU encode pipeline (canonical sort + dirty/feasible compaction + intra-frame dedup + subset-fold + per-pixel index emission), CPU Stage 4 rayon-parallel RLE byte-packing, persistent palette table with delivery tracking, TypeScript client decode with palette cache.

**Architecture:** Four new GPU compute shaders (plus a 16-element sort appended to `tile_analysis.comp`) record into the existing capture command buffer, so all pipeline stages share a single submit and one fence-wait at end of frame. After the fence, CPU Stage 4 runs three phases over the dense compact list: Phase A serial palette-table allocation; Phase B rayon-parallel per-tile encode; Phase C integration into the existing `dispatch_dirty_tiles_via_scheduler` loop. The persistent `PaletteTable` carries lifecycle (`SlotState::{Empty, Held, FreeButCached}`, ref counts, `delivered` BitSet, `in_flight_carrying`) under a single-client invariant so no per-session iteration is needed. Wire format adds a `Codec::PalRle = 2` payload: 1 B flags + 1 B persistent palette id + optional bundled palette + nibble-packed RLE bytes.

**Tech Stack:** Rust (workspace member `ghostframe-lib`), TypeScript (`ghostframe-web-client`), Vulkan compute via `ash` 0.38 (GLSL 450 → SPIR-V), rayon for CPU parallelism, QUIC datagrams via tsnet+quinn-proto, WebTransport on the browser side.

```rust
//! PalRLE tile codec — palette-indexed nibble-packed run-length encoding.
//!
//! Server-side state: `PaletteTable` carries persistent 256-slot lifecycle
//! (ref counts, `delivered` BitSet, `in_flight_carrying` counters) under
//! the M3.2a single-client invariant. See
//! `docs/superpowers/specs/2026-05-13-palrle-codec-design.md`.

use thiserror::Error;

/// Maximum colors in a PalRLE palette. Tiles with more unique colors fall
/// through the classifier to BC1/Cdf53.
pub const MAX_PALETTE_COUNT: usize = 16;

/// Persistent palette table capacity.
pub const PALETTE_TABLE_SLOTS: usize = 256;

/// Canonical palette entry. Colors are BGRA-ascending sorted (matching the
/// canonical sort appended to `tile_analysis.comp`).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct PaletteEntry {
    pub colors: [[u8; 4]; MAX_PALETTE_COUNT],
    pub count: u8,
}

impl Default for PaletteEntry {
    fn default() -> Self {
        Self {
            colors: [[0; 4]; MAX_PALETTE_COUNT],
            count: 0,
        }
    }
}

/// Per-slot lifecycle.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SlotState {
    Empty,
    Held,
    FreeButCached,
}

/// Per-frame palette-table activity, surfaced via tracing.
#[derive(Debug, Default, Clone, Copy)]
pub struct FramePaletteStats {
    pub reused_or_allocated: u32,
    pub fell_back_to_raw: u32,
}

#[derive(Debug, Error, PartialEq)]
pub enum PalRleDecodeError {
    #[error("payload too short: needed {needed} bytes at offset {offset}, got {got}")]
    Truncated { needed: usize, offset: usize, got: usize },

    #[error("thin payload references uncached palette id {0}")]
    UncachedPalette(u8),

    #[error("palette index {index} >= count {count}")]
    IndexOutOfRange { index: u8, count: u8 },

    #[error("decoded {decoded} pixels, expected 1024")]
    PixelCountMismatch { decoded: u32 },

    #[error("palette count {0} exceeds MAX_PALETTE_COUNT")]
    PaletteCountOutOfRange(u8),
}
```

```rust
/// Bitset over `PALETTE_TABLE_SLOTS` slots. Plain `[bool; 256]` form chosen
/// for simplicity (32 bytes) — no external crate needed.
#[derive(Debug, Clone, Copy)]
pub struct PaletteIdBitSet {
    bits: [bool; PALETTE_TABLE_SLOTS],
}

impl PaletteIdBitSet {
    pub fn new() -> Self {
        Self {
            bits: [false; PALETTE_TABLE_SLOTS],
        }
    }
    pub fn contains(&self, id: u8) -> bool {
        self.bits[id as usize]
    }
    pub fn insert(&mut self, id: u8) {
        self.bits[id as usize] = true;
    }
    pub fn remove(&mut self, id: u8) {
        self.bits[id as usize] = false;
    }
    pub fn clear(&mut self) {
        self.bits.fill(false);
    }
}

impl Default for PaletteIdBitSet {
    fn default() -> Self {
        Self::new()
    }
}

/// Persistent 256-slot palette table. Single-client invariant — owned
/// directly by `IoBridge`, no per-session wrapping (see design D3).
pub struct PaletteTable {
    pub entries: [Option<PaletteEntry>; PALETTE_TABLE_SLOTS],
    pub slot_state: [SlotState; PALETTE_TABLE_SLOTS],
    pub ref_count: [u32; PALETTE_TABLE_SLOTS],
    pub delivered: PaletteIdBitSet,
    pub in_flight_carrying: [u32; PALETTE_TABLE_SLOTS],
    pub free_lru: std::collections::VecDeque<u8>,
    pub stats_frame: FramePaletteStats,
}

impl PaletteTable {
    pub fn new() -> Self {
        Self {
            entries: [None; PALETTE_TABLE_SLOTS],
            slot_state: [SlotState::Empty; PALETTE_TABLE_SLOTS],
            ref_count: [0; PALETTE_TABLE_SLOTS],
            delivered: PaletteIdBitSet::new(),
            in_flight_carrying: [0; PALETTE_TABLE_SLOTS],
            free_lru: std::collections::VecDeque::new(),
            stats_frame: FramePaletteStats::default(),
        }
    }

    /// Linear scan over (Held ∪ FreeButCached) slots. Returns the first id
    /// whose `entries[id]` byte-equals `palette` (sorted-set equality —
    /// canonical sort is required upstream).
    pub fn find_matching(&self, palette: &PaletteEntry) -> Option<u8> {
        for id in 0..PALETTE_TABLE_SLOTS {
            if self.slot_state[id] == SlotState::Empty {
                continue;
            }
            if let Some(e) = &self.entries[id] {
                if e == palette {
                    return Some(id as u8);
                }
            }
        }
        None
    }

    /// Increment `ref_count[id]`; promote `FreeButCached` → `Held` if it was
    /// the entry-into-use transition. No-op for `Empty` (caller bug — debug
    /// assert).
    pub fn acquire(&mut self, id: u8) {
        debug_assert!(self.slot_state[id as usize] != SlotState::Empty);
        if self.slot_state[id as usize] == SlotState::FreeButCached {
            self.slot_state[id as usize] = SlotState::Held;
            // Remove from free_lru if present.
            self.free_lru.retain(|&x| x != id);
        }
        self.ref_count[id as usize] = self.ref_count[id as usize].saturating_add(1);
    }

    /// Decrement `ref_count[id]`; drop `Held` → `FreeButCached` at zero and
    /// push onto `free_lru` tail.
    pub fn release(&mut self, id: u8) {
        debug_assert!(self.slot_state[id as usize] == SlotState::Held);
        self.ref_count[id as usize] = self.ref_count[id as usize].saturating_sub(1);
        if self.ref_count[id as usize] == 0 {
            self.slot_state[id as usize] = SlotState::FreeButCached;
            self.free_lru.push_back(id);
        }
    }
}

impl Default for PaletteTable {
    fn default() -> Self {
        Self::new()
    }
}
```

```rust
    /// A slot's bytes can be safely overwritten when no in-flight tile
    /// could observe a mismatch between the bytes the server sent and the
    /// bytes currently in the slot. Two sufficient conditions, per design D4:
    /// - `delivered[id] == true` (client has rendered using these bytes)
    /// - `in_flight_carrying[id] == 0` AND `delivered[id] == false`
    ///   (bytes never reached the wire)
    /// Combined with the always-required `ref_count == 0` precondition.
    pub fn overwrite_eligible(&self, id: u8) -> bool {
        if self.ref_count[id as usize] != 0 {
            return false;
        }
        self.delivered.contains(id) || self.in_flight_carrying[id as usize] == 0
    }

    /// Replace the slot's bytes and reset the per-slot tracking state.
    /// Caller must have verified `overwrite_eligible` (debug assert here).
    pub fn write_bytes(&mut self, id: u8, palette: &PaletteEntry) {
        debug_assert!(self.overwrite_eligible(id) || self.slot_state[id as usize] == SlotState::Empty);
        self.entries[id as usize] = Some(*palette);
        self.slot_state[id as usize] = SlotState::Held;
        self.ref_count[id as usize] = 0;
        self.delivered.remove(id);
        self.in_flight_carrying[id as usize] = 0;
        // Make sure stale free_lru entries don't linger.
        self.free_lru.retain(|&x| x != id);
    }

    /// First Empty slot by id ascending. None if every slot is non-Empty.
    pub fn find_empty_slot(&self) -> Option<u8> {
        for id in 0..PALETTE_TABLE_SLOTS {
            if self.slot_state[id] == SlotState::Empty {
                return Some(id as u8);
            }
        }
        None
    }

    /// Oldest FreeButCached slot that passes `overwrite_eligible`.
    /// Drains ineligible front entries (they stay in free_lru in case they
    /// become eligible later via ACK).
    pub fn find_eligible_free_slot(&self) -> Option<u8> {
        // We walk in age order without mutating self — find first hit.
        for &id in &self.free_lru {
            if self.slot_state[id as usize] == SlotState::FreeButCached
                && self.overwrite_eligible(id)
            {
                return Some(id);
            }
        }
        None
    }
```

```rust
    /// Returns the slot id on success; `None` if every slot is `Held`
    /// or `FreeButCached` with no overwrite-eligible candidate.
    pub fn acquire_or_allocate(&mut self, palette: &PaletteEntry) -> Option<u8> {
        // 1. find_matching → reuse
        if let Some(id) = self.find_matching(palette) {
            self.acquire(id);
            return Some(id);
        }
        // 2. find_eligible_free_slot → overwrite
        if let Some(id) = self.find_eligible_free_slot() {
            self.write_bytes(id, palette);
            // write_bytes already cleared delivered & in_flight; slot is Held with rc=0.
            self.ref_count[id as usize] = 1;
            return Some(id);
        }
        // 3. find_empty_slot → write
        if let Some(id) = self.find_empty_slot() {
            self.write_bytes(id, palette);
            self.ref_count[id as usize] = 1;
            return Some(id);
        }
        // 4. fail
        None
    }
```

```rust
/// Walk 1024 nibbles in `packed_indices` row-major (low nibble of byte 0
/// = pixel 0, high nibble of byte 0 = pixel 1, …) and emit nibble-packed
/// RLE bytes: `(index << 4) | (run_len - 1)`. Max run is 16; longer runs
/// emit multiple bytes.
pub fn encode_pal_rle_indices(packed_indices: &[u8; 512]) -> Vec<u8> {
    let mut out: Vec<u8> = Vec::with_capacity(64); // typical best case
    let mut cur_idx: u8 = packed_indices[0] & 0x0F;
    let mut cur_run: u8 = 0;

    for pixel in 0..1024usize {
        let byte = packed_indices[pixel / 2];
        let idx = if pixel % 2 == 0 {
            byte & 0x0F
        } else {
            (byte >> 4) & 0x0F
        };

        if idx == cur_idx && cur_run < 16 {
            cur_run += 1;
        } else {
            out.push((cur_idx << 4) | (cur_run - 1));
            cur_idx = idx;
            cur_run = 1;
        }
    }
    // Flush final run.
    out.push((cur_idx << 4) | (cur_run - 1));
    out
}
```

```rust
/// Build the full PalRle wire payload: flags + palette_id +
/// optional bundled palette block + nibble-packed RLE bytes.
pub fn encode_pal_rle_payload(
    packed_indices: &[u8; 512],
    palette: &PaletteEntry,
    palette_id: u8,
    bundled: bool,
) -> Vec<u8> {
    let mut out: Vec<u8> = Vec::with_capacity(if bundled { 256 } else { 128 });
    out.push(if bundled { 0x01 } else { 0x00 }); // flags
    out.push(palette_id);
    if bundled {
        out.push(palette.count);
        for i in 0..palette.count as usize {
            out.extend_from_slice(&palette.colors[i]);
        }
    }
    out.extend(encode_pal_rle_indices(packed_indices));
    out
}

/// Returned bundle from `decode_pal_rle` — pixel data plus, if the payload
/// was bundled, the (palette_id, palette) the client should cache.
#[derive(Debug)]
pub struct DecodedPalRle {
    pub pixels: Vec<u8>, // 1024 × 4 BGRA bytes = 4096 bytes
    pub updated_palette: Option<(u8, PaletteEntry)>,
}

/// Server-side parity decoder. Mirrors `ghostframe-web-client/src/decoder.ts`
/// `decodePalRle`. Used in roundtrip tests; not on the runtime hot path.
pub fn decode_pal_rle(
    payload: &[u8],
    cached_palette: Option<&PaletteEntry>,
) -> Result<DecodedPalRle, PalRleDecodeError> {
    let needed = |n: usize, off: usize| -> Result<(), PalRleDecodeError> {
        if payload.len() < off + n {
            Err(PalRleDecodeError::Truncated {
                needed: n,
                offset: off,
                got: payload.len() - off.min(payload.len()),
            })
        } else {
            Ok(())
        }
    };

    needed(2, 0)?;
    let flags = payload[0];
    let palette_id = payload[1];
    let bundled = (flags & 0x01) != 0;

    let mut cursor = 2usize;
    let (palette_owned, palette_ref): (PaletteEntry, &PaletteEntry) = if bundled {
        needed(1, cursor)?;
        let count = payload[cursor];
        cursor += 1;
        if count as usize > MAX_PALETTE_COUNT || count == 0 {
            return Err(PalRleDecodeError::PaletteCountOutOfRange(count));
        }
        needed(count as usize * 4, cursor)?;
        let mut p = PaletteEntry::default();
        p.count = count;
        for i in 0..count as usize {
            p.colors[i].copy_from_slice(&payload[cursor..cursor + 4]);
            cursor += 4;
        }
        (p, /* placeholder, replaced below */ &PaletteEntry { colors: [[0; 4]; MAX_PALETTE_COUNT], count: 0 })
    } else {
        let cached = cached_palette.ok_or(PalRleDecodeError::UncachedPalette(palette_id))?;
        (PaletteEntry::default(), cached)
    };

    // Resolve a single borrow for the rest of decode.
    let palette: &PaletteEntry = if bundled { &palette_owned } else { palette_ref };

    // Decode RLE: each byte = (idx<<4) | (run-1). Total pixels must = 1024.
    let mut pixels = vec![0u8; 1024 * 4];
    let mut pixel_idx: u32 = 0;
    while cursor < payload.len() {
        let b = payload[cursor];
        cursor += 1;
        let idx = (b >> 4) & 0x0F;
        let run_len = ((b & 0x0F) as u32) + 1;
        if idx >= palette.count {
            return Err(PalRleDecodeError::IndexOutOfRange {
                index: idx,
                count: palette.count,
            });
        }
        let mut color = palette.colors[idx as usize];
        // Per design Section 7: force alpha=255 when source is 0 (BGRX quirk).
        if color[3] == 0 {
            color[3] = 255;
        }
        for _ in 0..run_len {
            if pixel_idx >= 1024 {
                return Err(PalRleDecodeError::PixelCountMismatch {
                    decoded: pixel_idx + 1,
                });
            }
            let off = (pixel_idx as usize) * 4;
            pixels[off..off + 4].copy_from_slice(&color);
            pixel_idx += 1;
        }
    }
    if pixel_idx != 1024 {
        return Err(PalRleDecodeError::PixelCountMismatch { decoded: pixel_idx });
    }

    let updated_palette = if bundled {
        Some((palette_id, palette_owned))
    } else {
        None
    };
    Ok(DecodedPalRle {
        pixels,
        updated_palette,
    })
}
```

```glsl
// palette_fold.comp
// Stage 2a: intra-frame palette dedup. Maps each PalRLE-feasible dirty tile
// to a frame_palette_set slot via open-addressed atomic hash table.
//
// Dispatch: vkCmdDispatchIndirect(palrle_indirect_dispatch_args), one
// workgroup per compact slot. 16 threads per workgroup (only thread 0 does
// the meaningful work; others idle).

#version 450

layout(local_size_x = 16, local_size_y = 1, local_size_z = 1) in;

struct TileAnalysis {
    uint  count;
    uint  edge_density_thou;
    uint  _pad0;
    uint  _pad1;
    uint  colors[16];
};

layout(binding = 0, std430) readonly buffer AnalysisInput {
    TileAnalysis tiles[];
};

layout(binding = 1, std430) readonly buffer CompactList {
    uint compact_list[];
};

struct PaletteEntry {
    uint count;
    uint _pad0;
    uint _pad1;
    uint _pad2;
    uint colors[16];
};
layout(binding = 2, std430) buffer FramePaletteSet {
    PaletteEntry frame_palettes[]; // 256 entries pre-allocated
};

layout(binding = 3, std430) buffer FramePaletteSetCount {
    uint frame_palette_count;
};

// Hash slot table: slot[i] = (hash<<16 | frame_palette_id+1)   0 means empty.
layout(binding = 4, std430) buffer HashTable {
    uint hash_slots[]; // 256 entries
};

layout(binding = 5, std430) buffer PerTileFramePaletteId {
    uint per_tile_id[]; // one entry per compact slot
};

// FNV-1a hash on the 16 packed colors (in canonical-sorted order).
uint fnv1a(uint tile_idx) {
    uint h = 2166136261u;
    uint c = tiles[tile_idx].count;
    for (uint i = 0u; i < c; i++) {
        uint v = tiles[tile_idx].colors[i];
        h ^= (v        ) & 0xFFu; h *= 16777619u;
        h ^= (v >>  8u) & 0xFFu; h *= 16777619u;
        h ^= (v >> 16u) & 0xFFu; h *= 16777619u;
        h ^= (v >> 24u) & 0xFFu; h *= 16777619u;
    }
    return h;
}

bool palettes_equal(uint tile_idx, uint pal_idx) {
    uint c = tiles[tile_idx].count;
    if (frame_palettes[pal_idx].count != c) return false;
    for (uint i = 0u; i < c; i++) {
        if (tiles[tile_idx].colors[i] != frame_palettes[pal_idx].colors[i]) return false;
    }
    return true;
}

const uint PROBE_BUDGET = 16u;
const uint SENTINEL = 0xFFu;

void main() {
    if (gl_LocalInvocationID.x != 0u) return;

    uint c_slot = gl_WorkGroupID.x;
    uint tile_idx = compact_list[c_slot];
    uint h = fnv1a(tile_idx);

    for (uint probe = 0u; probe < PROBE_BUDGET; probe++) {
        uint slot = (h + probe) & 0xFFu;
        uint expected = 0u;
        uint desired = (h & 0xFFFF0000u) | (slot + 1u);
        // Try to claim the slot.
        uint prev = atomicCompSwap(hash_slots[slot], expected, desired);
        if (prev == 0u) {
            // We claimed it. Write our palette bytes into frame_palettes[slot].
            uint cnt = tiles[tile_idx].count;
            frame_palettes[slot].count = cnt;
            for (uint i = 0u; i < cnt; i++) {
                frame_palettes[slot].colors[i] = tiles[tile_idx].colors[i];
            }
            // Track high-water mark.
            atomicMax(frame_palette_count, slot + 1u);
            per_tile_id[c_slot] = slot;
            return;
        }
        if ((prev & 0xFFFF0000u) == (h & 0xFFFF0000u)) {
            // Same hash; verify by byte compare.
            if (palettes_equal(tile_idx, slot)) {
                per_tile_id[c_slot] = slot;
                return;
            }
        }
        // Collision; continue probing.
    }
    // Probe budget exhausted → sentinel.
    per_tile_id[c_slot] = SENTINEL;
}
```

```glsl
// palette_subset_fold.comp
// Stage 2b: detect palette A ⊆ palette B and arrange A's tiles to use B.
//
// Dispatch: vkCmdDispatch(frame_palette_set_count, 1, 1) — one workgroup
// per unique frame palette. 256 threads per workgroup, one per candidate
// superset B.

#version 450

layout(local_size_x = 256, local_size_y = 1, local_size_z = 1) in;

struct PaletteEntry {
    uint count;
    uint _pad0;
    uint _pad1;
    uint _pad2;
    uint colors[16];
};
layout(binding = 0, std430) readonly buffer FramePaletteSet {
    PaletteEntry frame_palettes[];
};

layout(binding = 1, std430) readonly buffer FramePaletteSetCount {
    uint frame_palette_count;
};

layout(binding = 2, std430) buffer FoldedInto {
    uint folded_into[]; // 256 entries: encoded as (255 - count_B) << 8 | id_B
};

bool is_subset(uint a_pal_id, uint b_pal_id) {
    uint cnt_a = frame_palettes[a_pal_id].count;
    uint cnt_b = frame_palettes[b_pal_id].count;
    if (cnt_b < cnt_a) return false;

    // Linear sorted-set inclusion: walk both in ascending order.
    uint i = 0u;
    uint j = 0u;
    while (i < cnt_a && j < cnt_b) {
        uint a = frame_palettes[a_pal_id].colors[i];
        uint b = frame_palettes[b_pal_id].colors[j];
        if (a == b) {
            i++; j++;
        } else if (a < b) {
            // a not in b → not subset
            return false;
        } else {
            j++;
        }
    }
    return i == cnt_a;
}

void main() {
    uint a_id = gl_WorkGroupID.x;
    if (a_id >= frame_palette_count) return;

    uint b_id = gl_LocalInvocationID.x;
    if (b_id >= frame_palette_count) return;
    if (b_id == a_id) return;

    uint cnt_a = frame_palettes[a_id].count;
    uint cnt_b = frame_palettes[b_id].count;
    if (cnt_b < cnt_a) return; // can't be a superset

    if (is_subset(a_id, b_id)) {
        // Encode tiebreaker: larger count wins, then lower id.
        uint key = ((255u - cnt_b) << 8u) | b_id;
        atomicMin(folded_into[a_id], key);
    }
}
```

```glsl
// pal_rle_index.comp
// Stage 3: per-pixel palette lookup → 4-bit index, packed atomically into a
// shared scratch buffer, then bulk-written to global index_buffer.
//
// Dispatch: vkCmdDispatchIndirect(palrle_indirect_dispatch_args).
// One workgroup per compact slot, 32×32 = 1024 threads per workgroup.

#version 450

layout(local_size_x = 32, local_size_y = 32, local_size_z = 1) in;

layout(binding = 0, rgba8) readonly uniform image2D current_frame;

layout(binding = 1, std430) readonly buffer CompactList {
    uint compact_list[];
};

struct PaletteEntry {
    uint count;
    uint _pad0;
    uint _pad1;
    uint _pad2;
    uint colors[16];
};
layout(binding = 2, std430) readonly buffer FramePaletteSet {
    PaletteEntry frame_palettes[];
};

layout(binding = 3, std430) readonly buffer PerTileFramePaletteId {
    uint per_tile_id_packed[]; // u8 entries packed into u32s, little-endian
};

layout(binding = 4, std430) readonly buffer FoldedInto {
    uint folded_into[];
};

layout(binding = 5, std430) buffer IndexBuffer {
    uint index_buffer_u32[]; // each tile: 128 u32 entries = 512 bytes
};

layout(push_constant) uniform PushConstants {
    uint cols;
};

shared uint scratch[128]; // 1024 nibbles = 128 u32s
shared uint shared_palette[16];
shared uint shared_count;

uint pack_bgra(vec4 p) {
    uint b = uint(p.b * 255.0 + 0.5);
    uint g = uint(p.g * 255.0 + 0.5);
    uint r = uint(p.r * 255.0 + 0.5);
    uint a = uint(p.a * 255.0 + 0.5);
    return b | (g << 8) | (r << 16) | (a << 24);
}

// Binary search on canonical-sorted palette.
uint binary_search(uint packed, uint count) {
    uint lo = 0u;
    uint hi = count;
    while (lo < hi) {
        uint mid = (lo + hi) >> 1u;
        if (shared_palette[mid] < packed) {
            lo = mid + 1u;
        } else {
            hi = mid;
        }
    }
    // Caller ensures `packed` is in the palette (classifier feasibility).
    // Defensive: clamp to count-1 if not found.
    if (lo >= count) lo = count - 1u;
    return lo;
}

void main() {
    uint local_idx = gl_LocalInvocationID.y * 32u + gl_LocalInvocationID.x;
    uint c_slot = gl_WorkGroupID.x;
    uint tile_idx = compact_list[c_slot];

    // Read per_tile_id (packed u8 → u32 index). 4 u8 per u32.
    uint packed_word = per_tile_id_packed[c_slot >> 2u];
    uint shift = (c_slot & 3u) * 8u;
    uint frame_pal_id_local = (packed_word >> shift) & 0xFFu;

    // Skip if sentinel (0xFF) — caller's CPU code filters.
    // Still must not write garbage; just early-out for the whole workgroup.
    bool skip = frame_pal_id_local == 0xFFu;

    uint effective_id = 0u;
    if (!skip) {
        effective_id = folded_into[frame_pal_id_local] & 0xFFu;
    }

    // Init shared state.
    if (local_idx < 128u) scratch[local_idx] = 0u;
    if (local_idx == 0u && !skip) {
        shared_count = frame_palettes[effective_id].count;
    }
    if (local_idx < 16u && !skip) {
        shared_palette[local_idx] = frame_palettes[effective_id].colors[local_idx];
    }
    barrier();

    if (skip) return;

    // Compute this thread's pixel BGRA.
    uint tile_x = tile_idx % cols;
    uint tile_y = tile_idx / cols;
    ivec2 frame_pixel = ivec2(int(tile_x * 32u + gl_LocalInvocationID.x),
                              int(tile_y * 32u + gl_LocalInvocationID.y));
    vec4 px = imageLoad(current_frame, frame_pixel);
    uint packed = pack_bgra(px);

    uint idx = binary_search(packed, shared_count);

    // Atomic-OR into shared scratch.
    uint word = local_idx >> 3u;        // local_idx / 8 → 0..127
    uint shift_bits = (local_idx & 7u) * 4u;
    atomicOr(scratch[word], idx << shift_bits);

    barrier();

    // First 128 threads write scratch back to global index_buffer.
    if (local_idx < 128u) {
        index_buffer_u32[c_slot * 128u + local_idx] = scratch[local_idx];
    }
}
```

```rust
    /// Phase A: serially walk the GPU's compact list, map each tile's
    /// frame-local palette id to a persistent slot via PaletteTable, and
    /// produce per-tile work preps.
    ///
    /// `compact_list[c]` = tile_idx; `per_tile_frame_palette_id[c]` = local
    /// palette id (0xFF = overflow sentinel); `folded_into[i]` resolves to
    /// the effective palette; `frame_palette_set[id]` carries the bytes;
    /// `index_buffer` slices to per-tile 512-byte indices.
    pub(crate) fn phase_a_palette_allocation(
        &mut self,
        cols: u32,
        compact_list: &[u32],
        per_tile_frame_palette_id: &[u8],
        folded_into: &[u32], // 256 entries
        frame_palette_set: &[crate::capture::gpu_pipeline::FramePaletteEntryRaw],
        index_buffer: &[u8], // compact_list.len() * 512 bytes
    ) -> Vec<PalRleTileWorkPrep> {
        use crate::encoder::pal_rle::PaletteEntry;
        use crate::tile::CodecState;

        let mut preps: Vec<PalRleTileWorkPrep> = Vec::with_capacity(compact_list.len());
        for (c, &tile_idx) in compact_list.iter().enumerate() {
            let tx = tile_idx % cols;
            let ty = tile_idx / cols;

            // Skip tiles where the classifier picked something else.
            if !matches!(
                self.metrics_tracker.get(tx, ty).codec_state,
                CodecState::PalRle { .. }
            ) {
                continue;
            }

            let pal_id_local = per_tile_frame_palette_id[c];
            if pal_id_local == 0xFF {
                self.metrics_tracker.get_mut(tx, ty).codec_state = CodecState::Skip;
                self.palette_table.stats_frame.fell_back_to_raw += 1;
                continue;
            }
            let effective = (folded_into[pal_id_local as usize] & 0xFF) as usize;
            let raw = &frame_palette_set[effective];
            let mut palette = PaletteEntry::default();
            palette.count = raw.count as u8;
            for i in 0..palette.count as usize {
                let v = raw.colors[i];
                palette.colors[i] = [
                    (v & 0xFF) as u8,
                    ((v >> 8) & 0xFF) as u8,
                    ((v >> 16) & 0xFF) as u8,
                    ((v >> 24) & 0xFF) as u8,
                ];
            }

            match self.palette_table.acquire_or_allocate(&palette) {
                Some(id) => {
                    let bundled = !self.palette_table.delivered.contains(id);
                    if bundled {
                        self.palette_table.in_flight_carrying[id as usize] += 1;
                    }
                    let mut indices = [0u8; 512];
                    indices.copy_from_slice(&index_buffer[c * 512 .. (c + 1) * 512]);
                    self.metrics_tracker.get_mut(tx, ty).codec_state =
                        CodecState::PalRle { palette_id: id };
                    self.palette_table.stats_frame.reused_or_allocated += 1;
                    preps.push(PalRleTileWorkPrep {
                        tile_xy: (tx, ty),
                        indices,
                        palette,
                        palette_id: id,
                        bundled,
                    });
                }
                None => {
                    self.metrics_tracker.get_mut(tx, ty).codec_state = CodecState::Skip;
                    self.palette_table.stats_frame.fell_back_to_raw += 1;
                }
            }
        }
        preps
    }
```

**Files:**

- [ ] **Step 1: Add DecodeError class + decodePalRle**

Open `ghostframe-web-client/src/decoder.ts`. At the top, alongside other exports:

```ts
import { PaletteCache, type Bgra, type PaletteId } from "./palette.js";

export class PalRleDecodeError extends Error {
    constructor(message: string) {
        super(message);
        this.name = "PalRleDecodeError";
    }
}

export interface DecodedPalRle {
    bgra: Uint8ClampedArray;
    updatedPaletteId?: PaletteId;
}

export function decodePalRle(
    payload: Uint8Array,
    cache: PaletteCache,
): DecodedPalRle {
    if (payload.length < 2) {
        throw new PalRleDecodeError(`PalRle payload too short: ${payload.length}`);
    }
    let cursor = 0;
    const flags = payload[cursor++];
    const paletteId = payload[cursor++];
    const bundled = (flags & 0x01) !== 0;

    let palette: Bgra[];
    let updated: PaletteId | undefined;

    if (bundled) {
        if (cursor >= payload.length) {
            throw new PalRleDecodeError("PalRle bundled payload missing count");
        }
        const count = payload[cursor++];
        if (count < 1 || count > 16) {
            throw new PalRleDecodeError(`PalRle count ${count} out of range`);
        }
        if (cursor + count * 4 > payload.length) {
            throw new PalRleDecodeError(
                `PalRle bundled payload truncated: need ${count * 4} more bytes`,
            );
        }
        const colors: Bgra[] = new Array(count);
        for (let i = 0; i < count; i++) {
            colors[i] = [
                payload[cursor++],
                payload[cursor++],
                payload[cursor++],
                payload[cursor++],
            ];
        }
        cache.upsert(paletteId, colors);
        palette = colors;
        updated = paletteId;
    } else {
        const cached = cache.get(paletteId);
        if (!cached) {
            throw new PalRleDecodeError(
                `PalRle thin payload references uncached palette ${paletteId}`,
            );
        }
        palette = cached;
    }

    const bgra = new Uint8ClampedArray(32 * 32 * 4);
    let pixelIdx = 0;
    while (cursor < payload.length) {
        const b = payload[cursor++];
        const colorIdx = (b >> 4) & 0x0F;
        const runLen = (b & 0x0F) + 1;
        if (colorIdx >= palette.length) {
            throw new PalRleDecodeError(
                `palette index ${colorIdx} >= count ${palette.length}`,
            );
        }
        let [bb, gg, rr, aa] = palette[colorIdx];
        // Force alpha = 255 to work around X11 BGRX alpha=0 quirk
        // (see memory: feedback_canvas_alpha.md).
        if (aa === 0) aa = 255;
        for (let i = 0; i < runLen; i++) {
            if (pixelIdx >= 1024) {
                throw new PalRleDecodeError(
                    `PalRle decoded ${pixelIdx + 1} pixels, expected 1024`,
                );
            }
            const offset = pixelIdx * 4;
            bgra[offset] = bb;
            bgra[offset + 1] = gg;
            bgra[offset + 2] = rr;
            bgra[offset + 3] = aa;
            pixelIdx++;
        }
    }
    if (pixelIdx !== 1024) {
        throw new PalRleDecodeError(
            `PalRle decoded ${pixelIdx} pixels, expected 1024`,
        );
    }
    return { bgra, updatedPaletteId: updated };
}
```

```ts
export function drawPalRleTile(
    ctx: CanvasRenderingContext2D,
    tileX: number,
    tileY: number,
    bgra: Uint8ClampedArray,
): void {
    // Note: ImageData is RGBA in browsers, but our decoder emits BGRA bytes.
    // The pixel byte order shouldn't matter for putImageData because we
    // wrote each pixel as [B, G, R, A] and Canvas interprets [R, G, B, A].
    // We need to swap B/R per pixel before putImageData.
    const rgba = new Uint8ClampedArray(bgra.length);
    for (let i = 0; i < bgra.length; i += 4) {
        rgba[i]     = bgra[i + 2]; // R from B-slot
        rgba[i + 1] = bgra[i + 1]; // G
        rgba[i + 2] = bgra[i];     // B from R-slot
        rgba[i + 3] = bgra[i + 3]; // A
    }
    const imageData = new ImageData(rgba, 32, 32);
    ctx.putImageData(imageData, tileX * 32, tileY * 32);
}
```

```rust
struct PalRleBench {
    palette_table: ghostframe_lib::encoder::pal_rle::PaletteTable,
}

impl PalRleBench {
    fn new() -> Self {
        Self {
            palette_table: ghostframe_lib::encoder::pal_rle::PaletteTable::new(),
        }
    }
}

impl BenchEncoder for PalRleBench {
    fn name(&self) -> &'static str {
        "palrle"
    }

    fn encode(&mut self, tile_bgra: &[u8; 4096]) -> Vec<u8> {
        // Build a palette from the unique colors in tile_bgra (capped at 16).
        // Real production uses GPU output; for bench we do a CPU scan.
        use ghostframe_lib::encoder::pal_rle::{
            encode_pal_rle_payload, PaletteEntry, MAX_PALETTE_COUNT,
        };
        let mut palette = PaletteEntry::default();
        let mut seen: Vec<[u8; 4]> = Vec::with_capacity(16);
        for chunk in tile_bgra.chunks_exact(4) {
            let c: [u8; 4] = chunk.try_into().unwrap();
            if !seen.contains(&c) {
                if seen.len() >= MAX_PALETTE_COUNT {
                    // Tile not PalRLE-feasible; return empty (bench harness records skip).
                    return Vec::new();
                }
                seen.push(c);
            }
        }
        seen.sort_by_key(|c| u32::from_le_bytes(*c));
        for (i, c) in seen.iter().enumerate() {
            palette.colors[i] = *c;
        }
        palette.count = seen.len() as u8;

        // Build the 4-bit index stream.
        let mut indices = [0u8; 512];
        for (pixel, chunk) in tile_bgra.chunks_exact(4).enumerate() {
            let c: [u8; 4] = chunk.try_into().unwrap();
            let idx = seen.iter().position(|x| x == &c).unwrap() as u8;
            let byte = pixel / 2;
            let shift = (pixel % 2) * 4;
            indices[byte] |= (idx & 0x0F) << shift;
        }

        let id = self
            .palette_table
            .acquire_or_allocate(&palette)
            .unwrap_or(0);
        let bundled = !self.palette_table.delivered.contains(id);
        encode_pal_rle_payload(&indices, &palette, id, bundled)
    }
}
```

## Post-merge addendum (2026-05-13)

Tasks 1–34 shipped as 60 commits on `master`. 250 lib tests passing, full build clean. This section documents what happened in execution that deviates from the plan, so future readers (and the M3.2b plan) start from accurate ground.

### Task splits

The plan's "single task" granularity proved too coarse for Tasks 10–13. Each ended up split into two commits/sessions during execution:

- **Task 10a / 10b** — Stage 1.5 palrle_compact: (a) shaders + SPIR-V + buffer/pipeline static setup in `GpuFrameProcessor::new`; (b) per-frame descriptor allocation + command-buffer recording + `FrameAnalysis` extension + GPU test.
- **Task 11a / 11b** — Stage 2a palette_fold: same split.
- **Task 12a / 12b** — Stage 2b palette_subset_fold: same split.
- **Task 13a / 13b** — Stage 3 pal_rle_index: same split.

The split was driven by file-size context limits — each Vulkan-static-setup is ~150–400 LoC of inline boilerplate, and combining with per-frame recording + tests pushed each task over a comfortable working size. Future M3.x plans for GPU shader integration should adopt the a/b split from the start.

### Codebase assumptions in the plan that didn't hold

Several "helper functions" the plan referenced do not exist in `gpu_pipeline.rs`:
- `build_compute_pipeline`, `descriptor_binding`, `memory_barrier`, `create_host_visible_buffer`, `create_device_local_buffer` — all imagined helpers. The codebase uses inline `ash` calls for every shader's descriptor set layout, pipeline layout, pipeline, buffer allocation, descriptor writes. ~80–150 LoC per shader.
- `build.sh` for shader compilation does not exist. Use `glslangValidator -V <name>.comp -o <name>.spv` manually.
- The plan's `DropPattern` enum for loss-injection doesn't exist; the codebase uses `DropPredicate = fn(&[u8]) -> bool` function pointers selected by string match in `IoBridge::loss_injector_from_env`.
- The plan's `bytemuck::cast_slice` call site assumed `bytemuck` was in scope; the actual call sites use the existing path through ash's `cmd_push_constants`.

Future plans for this codebase should reference inline patterns, not aspirational helpers. If helpers would genuinely improve clarity, propose them as a separate refactoring task.

### Real bugs the multi-stage review caught (per-task)

These are documented in detail at `~/.claude/projects/-home-cedric-work-ghostframe/memory/feedback_code_review_catches.md`. Quick list:

- Task 9: `0xFFFFFFFF` sort-padding sentinel collides with pure white BGRA — white pixels silently dropped from PalRLE tiles
- Task 9: `barrier()` doesn't cover StorageBuffer visibility — buffer reads after barrier are non-conformant; use shared variable instead
- Task 10a: shader dirty-threshold predicate `>=` vs CPU `>` mismatch at the boundary
- Task 10b: shader uses `gl_WorkGroupID.x` only but dispatch was `(cols, rows, 1)` — multi-row frames double-counted (caught by implementer's self-review)
- Task 10b: missing COMPUTE→COMPUTE inter-dispatch barrier on `sad_buffer`/`analysis_buffer`
- Task 10b: HOST barrier `srcStageMask` missing `TRANSFER` flag when any buffer barrier declared `TRANSFER_WRITE`
- Task 11a: hash table `0xFF` sentinel collides with valid slot 255 — reserved slot 255 as unusable instead
- Task 11b: `frame_palette_set_slice` semantics were "sparse slice indexed by count" but the buffer is hash-indexed; changed to full 256-entry slice with caller using indices from `per_tile_frame_palette_id` + `folded_into`
- Task 11b: Stage 1.5/2a barriers depend on `frame_palette_set_buffer` being zero-filled between frames (Task 12b's responsibility); added precondition comment to shader
- Task 8: proptest used `arb_indices_against(palette.count).new_tree(...).current()` which detaches from the outer RNG, breaking shrinking and `PROPTEST_SEED` reproducibility — fixed via `prop_flat_map`
- Task 8: range `0u8..=PALETTE_TABLE_SLOTS as u8` truncates `256 as u8 → 0`, silently producing `0..=0` — fixed to `0u8..32u8`
- Task 12a: subset_fold init sentinel `(0u << 8) | i` per spec was wrong — real superset keys are `((255 - count_B) << 8) | id_B`, all ≥ 61184; init value must be larger. Code uses `(255u << 8) | i` which is correct; spec doc has a typo.

### Real bug only the whole-implementation review caught

- **Missing `release()` call** (final-review catch): `PaletteTable::acquire_or_allocate` is called from Phase A and increments `ref_count`. `PaletteTable::release()` was never called in production code. Within a session, ref_counts monotonically ratcheted up; LRU eviction (which requires `ref_count == 0`) was dead. Sessions effectively had a depletion ceiling at 256 distinct palettes before falling through to `Codec::Raw`. `on_session_reset` masked the issue between sessions.

  **Fix** (commit `04d1dea`): added `palette_table.release(pid)` in both the ACK callback (after `delivered.insert` + `in_flight_carrying` decrement) and the supersession callback (in `bump_generation_collecting`'s loop), guarded by `if ref_count[pid_usize] > 0` to prevent double-release.

  **Why per-task reviews missed it:** Each per-task review focused on its own scope. The lifecycle spans 4 tasks (Phase A acquires in Task 18, scheduler holds the work in Tasks 19–21, ACK/supersession resolves in Task 22). The release-call gap sits in the seam between Tasks 18 and 22; no per-task reviewer saw both.

  **Lesson for future plans:** "Phase X acquires, Phase Y releases" patterns where X and Y are in separate tasks need an explicit "verify acquire/release pairing" item in the final review checklist. Better still: make the acquire call return a typed handle that must be passed to release, so Rust's type system catches the leak at compile time.

### Spec deviations worth noting

- `palrle_indirect_args_buffer` allocated as `HOST_VISIBLE | HOST_COHERENT` instead of `DEVICE_LOCAL` (plan said device-local). Implementer chose host-visible for simpler init (write `(0, 1, 1)` directly via mapped pointer). Functionally correct; minor perf deviation on discrete GPUs. Documented inline.
- Stage 2b dispatches a fixed `(256, 1, 1)` instead of indirect-dispatched on `frame_palette_set_count`. Functionally correct (slots are always 256-bounded; per-workgroup early-exit handles unused slots). Spec language was aspirational; fixed dispatch is the pragmatic choice.
