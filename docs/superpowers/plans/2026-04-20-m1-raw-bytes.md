# M1: Raw Bytes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Capture a real frame via DRM/KMS, break it into 32x32 tiles, ship raw pixels over QUIC datagrams with fragmentation, and paint them on a browser canvas.

**Architecture:** The xdaemon opens a DRM device, exports the framebuffer as a DMA-BUF fd, and mmaps it to read raw pixels. Pixels are submitted via `GhostframeServer::submit_frame()`, which sends a `FrameSubmission` over an mpsc channel to the `IoBridge` event loop. The IoBridge splits the frame into 32x32 tiles, fragments each tile into MTU-sized datagrams with a 12-byte datagram header + 8-byte tile header, and sends them via `WebTransportServer::send_datagram()`. The browser client reassembles fragments, decodes raw BGRA tiles, and paints them on a Canvas 2D surface.

**Tech Stack:** Rust (ghostframe-lib, ghostframe-xdaemon, ghostframe-test-pattern), TypeScript (browser client), `drm` crate (DRM/KMS), `x11rb` crate (test pattern), `libc::mmap` (DMA-BUF readback)

---

## Design Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| D1 | `mmap` first, then Vulkan DMA-BUF import | mmap validates the transport pipeline quickly (~20 lines). After the E2E test passes (Task 10), Task 11 replaces mmap with Vulkan DMA-BUF import (`ash` + `VK_EXT_external_memory_dma_buf`). This validates the Vulkan device setup before M2 adds compute shaders. Risk reduction: if Vulkan breaks, the E2E test is our regression gate. |
| D2 | `GhostframeServer` wraps `IoBridge` + mpsc channel | Clean separation: capture thread produces frames, IoBridge consumes them. No shared mutable state. |
| D3 | Tile header in every fragment | QUIC datagrams can arrive out-of-order. Including (tile_x, tile_y) in each fragment enables stateless reassembly keyed on (frame_seq, tile_x, tile_y). |
| D4 | Fragmentation at protocol layer, not QUIC stream | Datagrams are unreliable and unordered -- ideal for real-time video. Streams add head-of-line blocking. Fragmentation lets us fit tiles into QUIC datagram MTU. |
| D5 | C FFI (`ffi.rs`) included in M1 | Spec requires it; cbindgen was set up in M0 as non-fatal. M1 makes it load-bearing so the header is validated at build time. |
| D6 | Canvas 2D with `putImageData` | Simplest rendering path for raw BGRA tiles. WebGPU deferred to M3. |

//! Wire format for M1 tile datagrams.
//!
//! Each QUIC datagram carries one fragment of one tile:
//! ```text
//! [DatagramHeader: 12 bytes][TileHeader: 8 bytes][payload: variable]
//! ```
//! The receiver reassembles fragments keyed on (frame_seq, tile_x, tile_y).

pub const DATAGRAM_HEADER_SIZE: usize = 12;
pub const TILE_HEADER_SIZE: usize = 8;

// Keep M0 ping/pong for backward compat
pub const PING_PAYLOAD: &[u8; 4] = b"ping";
pub const PONG_PAYLOAD: &[u8; 4] = b"pong";

/// Identifies a datagram as part of a frame + fragment sequence.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct DatagramHeader {
    /// Monotonically increasing frame sequence number.
    pub frame_seq: u32,
    /// Zero-based index of this fragment within the tile.
    pub frag_idx: u16,
    /// Total number of fragments for this tile.
    pub frag_total: u16,
    /// Capture timestamp in microseconds (wraps at ~71 minutes).
    pub timestamp_us: u32,
}

impl DatagramHeader {
    pub fn encode(&self, buf: &mut Vec<u8>) {
        buf.extend_from_slice(&self.frame_seq.to_be_bytes());
        buf.extend_from_slice(&self.frag_idx.to_be_bytes());
        buf.extend_from_slice(&self.frag_total.to_be_bytes());
        buf.extend_from_slice(&self.timestamp_us.to_be_bytes());
    }

    pub fn decode(data: &[u8]) -> Result<Self, ProtocolError> {
        if data.len() < DATAGRAM_HEADER_SIZE {
            return Err(ProtocolError::TooShort {
                expected: DATAGRAM_HEADER_SIZE,
                got: data.len(),
            });
        }
        Ok(Self {
            frame_seq: u32::from_be_bytes(data[0..4].try_into().unwrap()),
            frag_idx: u16::from_be_bytes(data[4..6].try_into().unwrap()),
            frag_total: u16::from_be_bytes(data[6..8].try_into().unwrap()),
            timestamp_us: u32::from_be_bytes(data[8..12].try_into().unwrap()),
        })
    }
}

#[derive(Debug, thiserror::Error)]
pub enum ProtocolError {
    #[error("buffer too short: expected {expected}, got {got}")]
    TooShort { expected: usize, got: usize },
    #[error("unknown codec: {0}")]
    UnknownCodec(u8),
}
```

/// Codec identifier. Bits [7:1] of the codec_lz4 byte.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u8)]
pub enum Codec {
    Skip = 0,
    H264 = 1,
    PalRle = 2,
    Bc1 = 3,
    Solid = 4,
    Raw = 5,
    Cdf53 = 6,
}

impl Codec {
    pub fn from_u8(v: u8) -> Result<Self, ProtocolError> {
        match v {
            0 => Ok(Self::Skip),
            1 => Ok(Self::H264),
            2 => Ok(Self::PalRle),
            3 => Ok(Self::Bc1),
            4 => Ok(Self::Solid),
            5 => Ok(Self::Raw),
            6 => Ok(Self::Cdf53),
            _ => Err(ProtocolError::UnknownCodec(v)),
        }
    }
}

/// Per-tile header. Present in every fragment so reassembly is stateless.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct TileHeader {
    pub tile_x: u8,
    pub tile_y: u8,
    /// Codec used for this tile's payload.
    pub codec: Codec,
    /// Whether the payload is LZ4-compressed after codec encoding.
    pub lz4: bool,
    /// Generation counter for progressive refinement (M3).
    pub generation: u8,
    /// Total payload length before fragmentation.
    pub payload_len: u32,
}

impl TileHeader {
    pub fn encode(&self, buf: &mut Vec<u8>) {
        buf.push(self.tile_x);
        buf.push(self.tile_y);
        let codec_lz4 = ((self.codec as u8) << 1) | (self.lz4 as u8);
        buf.push(codec_lz4);
        buf.push(self.generation);
        buf.extend_from_slice(&self.payload_len.to_be_bytes());
    }

    pub fn decode(data: &[u8]) -> Result<Self, ProtocolError> {
        if data.len() < TILE_HEADER_SIZE {
            return Err(ProtocolError::TooShort {
                expected: TILE_HEADER_SIZE,
                got: data.len(),
            });
        }
        let codec_lz4 = data[2];
        Ok(Self {
            tile_x: data[0],
            tile_y: data[1],
            codec: Codec::from_u8(codec_lz4 >> 1)?,
            lz4: (codec_lz4 & 1) != 0,
            generation: data[3],
            payload_len: u32::from_be_bytes(data[4..8].try_into().unwrap()),
        })
    }
}

/// Fragment a tile's payload into MTU-sized datagrams.
///
/// Each datagram contains: [DatagramHeader][TileHeader][payload_fragment].
/// `max_fragment_payload` is the max bytes of tile data per datagram
/// (excluding headers).
pub fn fragment_tile(
    frame_seq: u32,
    tile_x: u8,
    tile_y: u8,
    codec: Codec,
    payload: &[u8],
    timestamp_us: u32,
    max_fragment_payload: usize,
) -> Vec<Vec<u8>> {
    let total_len = payload.len();
    if total_len == 0 {
        // Single datagram with empty payload (e.g., Skip codec).
        let mut buf = Vec::with_capacity(DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE);
        DatagramHeader {
            frame_seq,
            frag_idx: 0,
            frag_total: 1,
            timestamp_us,
        }
        .encode(&mut buf);
        TileHeader {
            tile_x,
            tile_y,
            codec,
            lz4: false,
            generation: 0,
            payload_len: 0,
        }
        .encode(&mut buf);
        return vec![buf];
    }

    let frag_total = (total_len + max_fragment_payload - 1) / max_fragment_payload;
    let mut datagrams = Vec::with_capacity(frag_total);

    for i in 0..frag_total {
        let start = i * max_fragment_payload;
        let end = std::cmp::min(start + max_fragment_payload, total_len);
        let frag_data = &payload[start..end];

        let mut buf =
            Vec::with_capacity(DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE + frag_data.len());
        DatagramHeader {
            frame_seq,
            frag_idx: i as u16,
            frag_total: frag_total as u16,
            timestamp_us,
        }
        .encode(&mut buf);
        TileHeader {
            tile_x,
            tile_y,
            codec,
            lz4: false,
            generation: 0,
            payload_len: total_len as u32,
        }
        .encode(&mut buf);
        buf.extend_from_slice(frag_data);
        datagrams.push(buf);
    }

    datagrams
}

/// Decode a datagram into its header, tile header, and payload fragment.
///
/// Returns (DatagramHeader, TileHeader, &[u8] payload fragment).
pub fn decode_tile_datagram(data: &[u8]) -> Result<(DatagramHeader, TileHeader, &[u8]), ProtocolError> {
    let dh = DatagramHeader::decode(data)?;
    let th = TileHeader::decode(&data[DATAGRAM_HEADER_SIZE..])?;
    let payload_start = DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE;
    let payload = if payload_start <= data.len() {
        &data[payload_start..]
    } else {
        &[]
    };
    Ok((dh, th, payload))
}

/// Compute the maximum tile payload bytes per datagram given the max datagram size.
///
/// `max_datagram_size` is the total bytes available in one QUIC datagram
/// (from `conn.datagrams().max_size()` minus the WebTransport VarInt prefix).
pub fn max_fragment_payload(max_datagram_size: usize) -> usize {
    max_datagram_size.saturating_sub(DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE)
}
```

//! Tile grid: splits a frame buffer into 32x32 pixel tiles.

/// Tile size in pixels (width and height).
pub const TILE_SIZE: u32 = 32;
/// Bytes per pixel (BGRA).
pub const BPP: u32 = 4;
/// Bytes per full tile payload.
pub const TILE_BYTES: usize = (TILE_SIZE * TILE_SIZE * BPP) as usize;

/// A grid of 32x32 tiles covering a frame of `width x height` pixels.
#[derive(Debug, Clone)]
pub struct TileGrid {
    pub width: u32,
    pub height: u32,
    pub cols: u32,
    pub rows: u32,
}

impl TileGrid {
    pub fn new(width: u32, height: u32) -> Self {
        Self {
            width,
            height,
            cols: (width + TILE_SIZE - 1) / TILE_SIZE,
            rows: (height + TILE_SIZE - 1) / TILE_SIZE,
        }
    }

    pub fn tile_count(&self) -> u32 {
        self.cols * self.rows
    }

    /// Extract a tile's pixels from a frame buffer, always returning a
    /// full 32x32x4 buffer. Edge tiles are zero-padded.
    ///
    /// `stride` is the number of bytes per row in the source buffer.
    pub fn extract_tile(&self, pixels: &[u8], stride: u32, tile_x: u32, tile_y: u32) -> Vec<u8> {
        let mut tile = vec![0u8; TILE_BYTES];
        let src_x = tile_x * TILE_SIZE;
        let src_y = tile_y * TILE_SIZE;
        let copy_w = std::cmp::min(TILE_SIZE, self.width.saturating_sub(src_x));
        let copy_h = std::cmp::min(TILE_SIZE, self.height.saturating_sub(src_y));

        for row in 0..copy_h {
            let src_offset = ((src_y + row) * stride + src_x * BPP) as usize;
            let dst_offset = (row * TILE_SIZE * BPP) as usize;
            let row_bytes = (copy_w * BPP) as usize;
            if src_offset + row_bytes <= pixels.len() {
                tile[dst_offset..dst_offset + row_bytes]
                    .copy_from_slice(&pixels[src_offset..src_offset + row_bytes]);
            }
        }

        tile
    }

    /// Iterate all tile coordinates (col, row) in row-major order.
    pub fn iter_coords(&self) -> impl Iterator<Item = (u32, u32)> + '_ {
        (0..self.rows).flat_map(move |row| (0..self.cols).map(move |col| (col, row)))
    }
}
```

/// A captured frame ready for tiling and transmission.
pub struct FrameSubmission {
    pub width: u32,
    pub height: u32,
    /// Bytes per row in the pixel buffer (may include padding).
    pub stride: u32,
    /// BGRA pixel data, `stride * height` bytes.
    pub pixels: Vec<u8>,
    /// Capture timestamp in microseconds.
    pub timestamp_us: u32,
}

/// High-level server: manages the transport layer and accepts frame submissions.
pub struct GhostframeServer {
    frame_tx: mpsc::Sender<FrameSubmission>,
    cert_hash: String,
    _io_task: tokio::task::JoinHandle<()>,
}

impl GhostframeServer {
    /// Start the server: connect to Tailscale, open QUIC listener, spawn I/O loop.
    pub async fn new(
        config: GhostbridgeConfig,
        listen_addr: &str,
    ) -> Result<Self, Box<dyn std::error::Error + Send + Sync>> {
        let (frame_tx, frame_rx) = mpsc::channel::<FrameSubmission>(2);
        let mut bridge = IoBridge::new_with_frames(&config, listen_addr, frame_rx).await?;
        let cert_hash = bridge.cert_hash_sha256().to_string();
        let io_task = tokio::spawn(async move {
            if let Err(e) = bridge.run().await {
                tracing::error!("IoBridge error: {e}");
            }
        });
        Ok(Self {
            frame_tx,
            cert_hash,
            _io_task: io_task,
        })
    }

    /// Submit a captured frame for tiling and transmission.
    pub async fn submit_frame(
        &self,
        frame: FrameSubmission,
    ) -> Result<(), mpsc::error::SendError<FrameSubmission>> {
        self.frame_tx.send(frame).await
    }

    /// SHA-256 hex fingerprint of the server's self-signed certificate.
    pub fn cert_hash(&self) -> &str {
        &self.cert_hash
    }
}

                seq,
                tile_x as u8,
                tile_y as u8,
                Codec::Raw,

                frame.timestamp_us,
                max_frag,

//! DMA-BUF pixel readback via mmap.
//!
//! M1: simple mmap of the DMA-BUF fd to read raw pixels.
//! M2: this will be replaced with Vulkan DMA-BUF import + compute shaders.

use std::io;

/// Read pixels from a DMA-BUF file descriptor via mmap.
///
/// Returns a `Vec<u8>` of BGRA pixel data, `stride * height` bytes.
/// The caller is responsible for the fd's lifetime (this function does not
/// close it).
pub fn readback_dmabuf(
    fd: std::os::unix::io::RawFd,
    _width: u32,
    height: u32,
    stride: u32,
) -> io::Result<Vec<u8>> {
    let size = (stride * height) as usize;
    if size == 0 {
        return Ok(Vec::new());
    }

    unsafe {
        let ptr = libc::mmap(
            std::ptr::null_mut(),
            size,
            libc::PROT_READ,
            libc::MAP_SHARED,
            fd,
            0,
        );
        if ptr == libc::MAP_FAILED {
            return Err(io::Error::last_os_error());
        }

        let mut pixels = vec![0u8; size];
        std::ptr::copy_nonoverlapping(ptr as *const u8, pixels.as_mut_ptr(), size);

        libc::munmap(ptr, size);
        Ok(pixels)
    }
}

//! DRM/KMS framebuffer capture.
//!
//! Opens /dev/dri/card0, finds the active CRTC's framebuffer, and exports
//! it as a DMA-BUF fd for pixel readback.

use std::fs::OpenOptions;
use std::io;
use std::os::unix::io::{AsRawFd, OwnedFd, RawFd};

use drm::control::{Device as ControlDevice, ResourceHandle};
use drm::Device;

/// A DRM card opened for framebuffer capture.
pub struct DrmCapture {
    card: Card,
}

// Minimal wrapper to satisfy drm crate's trait bounds.
struct Card(std::fs::File);

impl AsRawFd for Card {
    fn as_raw_fd(&self) -> RawFd {
        self.0.as_raw_fd()
    }
}
impl Device for Card {}
impl ControlDevice for Card {}

/// Information about a captured framebuffer.
pub struct CapturedFb {
    pub width: u32,
    pub height: u32,
    pub stride: u32,
    pub dmabuf_fd: OwnedFd,
}

impl DrmCapture {
    /// Open a DRM card device (e.g., `/dev/dri/card0`).
    pub fn open(path: &str) -> io::Result<Self> {
        let file = OpenOptions::new().read(true).write(true).open(path)?;
        // Need to be DRM master or have appropriate permissions.
        // In our test container, we run as root so this should work.
        Ok(Self { card: Card(file) })
    }

    /// Capture the current framebuffer from the first active CRTC.
    ///
    /// Returns framebuffer dimensions, stride, and a DMA-BUF fd.
    pub fn capture(&self) -> io::Result<CapturedFb> {
        let resources = self
            .card
            .resource_handles()
            .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;

        // Find the first active CRTC with a framebuffer.
        for &crtc_handle in resources.crtcs() {
            let crtc = self
                .card
                .get_crtc(crtc_handle)
                .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;

            if let Some(fb_handle) = crtc.framebuffer() {
                let fb2 = self
                    .card
                    .get_framebuffer2(fb_handle)
                    .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;

                let handle = fb2.handles()[0];
                let fd = self
                    .card
                    .buffer_to_prime_fd(handle, drm::buffer::DrmFlags::RDWR)
                    .map_err(|e| io::Error::new(io::ErrorKind::Other, e))?;

                return Ok(CapturedFb {
                    width: fb2.size().0,
                    height: fb2.size().1,
                    stride: fb2.pitches()[0],
                    dmabuf_fd: fd,
                });
            }
        }

        Err(io::Error::new(
            io::ErrorKind::NotFound,
            "no active CRTC with framebuffer found",
        ))
    }
}
```

//! X11 test pattern app for E2E tests.
//!
//! Draws deterministic color patterns on an X11 window so the E2E test can
//! verify pixel-level correctness of the capture + transport pipeline.

use clap::Parser;
use x11rb::connection::Connection;
use x11rb::protocol::xproto::*;
use x11rb::wrapper::ConnectionExt as _;

#[derive(Parser)]
struct Args {
    /// Draw a solid red 200x200 square at (100, 100).
    #[arg(long)]
    solid_red: bool,

    /// Window width.
    #[arg(long, default_value = "640")]
    width: u16,

    /// Window height.
    #[arg(long, default_value = "480")]
    height: u16,
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let args = Args::parse();
    let (conn, screen_num) = x11rb::connect(None)?;
    let screen = &conn.setup().roots[screen_num];

    let win = conn.generate_id()?;
    conn.create_window(
        screen.root_depth,
        win,
        screen.root,
        0, 0,
        args.width, args.height,
        0,
        WindowClass::INPUT_OUTPUT,
        screen.root_visual,
        &CreateWindowAux::new()
            .background_pixel(screen.black_pixel)
            .event_mask(EventMask::EXPOSURE),
    )?;
    conn.map_window(win)?;

    let gc = conn.generate_id()?;
    conn.create_gc(gc, win, &CreateGCAux::default())?;

    loop {
        let event = conn.wait_for_event()?;
        match event {
            x11rb::protocol::Event::Expose(_) => {
                if args.solid_red {
                    draw_solid_red(&conn, win, gc)?;
                }
                conn.flush()?;
            }
            _ => {}
        }
    }
}

    conn.poly_fill_rectangle(win, gc, &[Rectangle {
        x: 100,
        y: 100,
        width: 200,
        height: 200,
    }])?;
    Ok(())
}

        match drm.capture() {

                    fb.dmabuf_fd.as_raw_fd(),
                    fb.width,
                    fb.height,
                    fb.stride,

                    width: fb.width,
                    height: fb.height,
                    stride: fb.stride,

                    tracing::warn!("frame submission failed (channel closed?): {e}");
                    break;

                tracing::warn!("DRM capture failed: {e}");
            }
        }

        let elapsed = capture_start.elapsed();
        if elapsed < frame_interval {
            tokio::time::sleep(frame_interval - elapsed).await;
        }
    }

    Ok(())

//! C FFI for ghostframe-lib.
//!
//! These functions are exported as `extern "C"` so non-Rust consumers
//! (e.g., an Enlightenment module in M6) can drive the server.
//!
//! The Rust `GhostframeServer` is heap-allocated and returned as an
//! opaque pointer. The caller must call `gf_server_destroy` to free it.

use std::ffi::CStr;
use std::os::raw::c_char;

use crate::server::{FrameSubmission, GhostframeServer};
use crate::transport::ghostbridge::GhostbridgeConfig;

/// Opaque handle to a running GhostframeServer.
pub type GfServerHandle = *mut GhostframeServer;

/// Create and start a new GhostframeServer.
///
/// Returns a handle on success, or null on failure.
/// `hostname`, `authkey`, `state_dir`, `control_url` are NUL-terminated C strings.
///
/// # Safety
/// All string pointers must be valid, NUL-terminated C strings.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn gf_server_new(
    hostname: *const c_char,
    authkey: *const c_char,
    state_dir: *const c_char,
    control_url: *const c_char,
) -> GfServerHandle {
    let config = GhostbridgeConfig {
        hostname: unsafe { CStr::from_ptr(hostname) }
            .to_string_lossy()
            .into_owned(),
        authkey: unsafe { CStr::from_ptr(authkey) }
            .to_string_lossy()
            .into_owned(),
        state_dir: unsafe { CStr::from_ptr(state_dir) }
            .to_string_lossy()
            .into_owned(),
        control_url: unsafe { CStr::from_ptr(control_url) }
            .to_string_lossy()
            .into_owned(),
    };

    // Create a tokio runtime for the async server.
    let rt = match tokio::runtime::Runtime::new() {
        Ok(rt) => rt,
        Err(_) => return std::ptr::null_mut(),
    };

    match rt.block_on(GhostframeServer::new(config, ":4443")) {
        Ok(server) => Box::into_raw(Box::new(server)),
        Err(e) => {
            eprintln!("gf_server_new failed: {e}");
            std::ptr::null_mut()
        }
    }
}

/// Submit a frame for tiling and transmission.
///
/// `pixels` must point to `stride * height` bytes of BGRA data.
/// Returns 0 on success, -1 on failure.
///
/// # Safety
/// `handle` must be a valid pointer from `gf_server_new`.
/// `pixels` must be valid for `stride * height` bytes.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn gf_server_submit_frame(
    handle: GfServerHandle,
    width: u32,
    height: u32,
    stride: u32,
    pixels: *const u8,
    timestamp_us: u32,
) -> i32 {
    if handle.is_null() || pixels.is_null() {
        return -1;
    }
    let server = unsafe { &*handle };
    let size = (stride * height) as usize;
    let pixel_data = unsafe { std::slice::from_raw_parts(pixels, size) }.to_vec();

    let frame = FrameSubmission {
        width,
        height,
        stride,
        pixels: pixel_data,
        timestamp_us,
    };

    // We need a runtime context to call the async submit_frame.
    // Since the server was created with its own runtime, we use
    // a blocking channel instead.
    let rt = tokio::runtime::Handle::try_current();
    match rt {
        Ok(handle) => {
            if handle.block_on(server.submit_frame(frame)).is_ok() {
                0
            } else {
                -1
            }
        }
        Err(_) => -1,
    }
}

/// Destroy a GhostframeServer and free its resources.
///
/// # Safety
/// `handle` must be a valid pointer from `gf_server_new`, or null.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn gf_server_destroy(handle: GfServerHandle) {
    if !handle.is_null() {
        let _ = unsafe { Box::from_raw(handle) };
    }
}
```

/** Wire format constants matching ghostframe-lib/src/transport/protocol.rs */
export const DATAGRAM_HEADER_SIZE = 12;
export const TILE_HEADER_SIZE = 8;
export const TILE_SIZE = 32;

export const enum Codec {
  Skip = 0,
  H264 = 1,
  PalRle = 2,
  Bc1 = 3,
  Solid = 4,
  Raw = 5,
  Cdf53 = 6,
}

export interface DatagramHeader {
  frameSeq: number;
  fragIdx: number;
  fragTotal: number;
  timestampUs: number;
}

export interface TileHeader {
  tileX: number;
  tileY: number;
  codec: Codec;
  lz4: boolean;
  generation: number;
  payloadLen: number;
}

export function decodeDatagramHeader(view: DataView, offset: number): DatagramHeader {
  return {
    frameSeq: view.getUint32(offset, false),
    fragIdx: view.getUint16(offset + 4, false),
    fragTotal: view.getUint16(offset + 6, false),
    timestampUs: view.getUint32(offset + 8, false),
  };
}

export function decodeTileHeader(view: DataView, offset: number): TileHeader {
  const codecLz4 = view.getUint8(offset + 2);
  return {
    tileX: view.getUint8(offset),
    tileY: view.getUint8(offset + 1),
    codec: (codecLz4 >> 1) as Codec,
    lz4: (codecLz4 & 1) !== 0,
    generation: view.getUint8(offset + 3),
    payloadLen: view.getUint32(offset + 4, false),
  };
}

/** Key for the fragment reassembly map. */
export function tileKey(frameSeq: number, tileX: number, tileY: number): string {
  return `${frameSeq}:${tileX}:${tileY}`;
}

/** Reassembly buffer for one tile's fragments. */
export interface TileAssembly {
  header: TileHeader;
  fragments: (Uint8Array | null)[];
  received: number;
}

import { TILE_SIZE } from './decoder';

/** Canvas 2D renderer that paints BGRA tiles. */
export class TileRenderer {
  private ctx: CanvasRenderingContext2D;
  private canvas: HTMLCanvasElement;

  constructor(canvas: HTMLCanvasElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d')!;
  }

  /** Resize canvas to match frame dimensions. */
  resize(width: number, height: number) {
    if (this.canvas.width !== width || this.canvas.height !== height) {
      this.canvas.width = width;
      this.canvas.height = height;
    }
  }

  /** Paint a raw BGRA tile at (tileX, tileY). */
  drawRawTile(tileX: number, tileY: number, bgraData: Uint8Array) {
    const px = tileX * TILE_SIZE;
    const py = tileY * TILE_SIZE;

    // Convert BGRA to RGBA for ImageData.
    const rgba = new Uint8ClampedArray(TILE_SIZE * TILE_SIZE * 4);
    for (let i = 0; i < TILE_SIZE * TILE_SIZE; i++) {
      const s = i * 4;
      rgba[s]     = bgraData[s + 2]; // R <- B
      rgba[s + 1] = bgraData[s + 1]; // G <- G
      rgba[s + 2] = bgraData[s];     // B <- R
      rgba[s + 3] = bgraData[s + 3]; // A <- A
    }

    const imageData = new ImageData(rgba, TILE_SIZE, TILE_SIZE);
    this.ctx.putImageData(imageData, px, py);
  }
}

```typescript
import {
  DATAGRAM_HEADER_SIZE,
  TILE_HEADER_SIZE,
  Codec,
  decodeDatagramHeader,
  decodeTileHeader,
  tileKey,
  TileAssembly,
} from './decoder';
import { TileRenderer } from './renderer';

const statusEl = document.getElementById('status')!;
const logEl = document.getElementById('log')!;
const canvas = document.getElementById('canvas') as HTMLCanvasElement;

function log(msg: string) {
  const line = document.createElement('div');
  line.textContent = msg;
  logEl.appendChild(line);
  // Auto-scroll
  logEl.scrollTop = logEl.scrollHeight;
}

async function main() {
  const url = new URL(window.location.href);
  const serverHost = url.searchParams.get('host') ?? 'ghostframe-server:4443';
  const certHash = url.searchParams.get('certHash') ?? '';

  const wtUrl = `https://${serverHost}/`;
  log(`Connecting to ${wtUrl}...`);

  let transport: WebTransport;
  if (certHash) {
    transport = new WebTransport(wtUrl, {
      serverCertificateHashes: [{ algorithm: 'sha-256', value: hexToBuffer(certHash) }],
    });
  } else {
    transport = new WebTransport(wtUrl);
  }

  transport.closed.then(
    (info) => log(`Transport closed: code=${info.closeCode} reason=${info.reason}`),
    (err) => log(`Transport closed with error: ${err}`),
  );

  await transport.ready;
  log('Connected!');
  statusEl.textContent = 'Connected';

  const renderer = new TileRenderer(canvas);
  const assemblyMap = new Map<string, TileAssembly>();
  let framesRendered = 0;
  let latestFrameSeq = -1;

  const reader = transport.datagrams.readable.getReader();
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;

    const data = value as Uint8Array;
    if (data.byteLength < DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE) {
      // Too short for tile datagram. Check for M0 ping/pong compat.
      const text = new TextDecoder().decode(data);
      if (text === 'pong') {
        statusEl.textContent = 'Ping/Pong successful!';
        log('M0 compat: pong received');
      }
      continue;
    }

    const view = new DataView(data.buffer, data.byteOffset, data.byteLength);
    const dh = decodeDatagramHeader(view, 0);
    const th = decodeTileHeader(view, DATAGRAM_HEADER_SIZE);

    // Payload fragment starts after both headers.
    const fragStart = DATAGRAM_HEADER_SIZE + TILE_HEADER_SIZE;
    const fragData = data.subarray(fragStart);

    const key = tileKey(dh.frameSeq, th.tileX, th.tileY);

    let assembly = assemblyMap.get(key);
    if (!assembly) {
      assembly = {
        header: th,
        fragments: new Array(dh.fragTotal).fill(null),
        received: 0,
      };
      assemblyMap.set(key, assembly);
    }

    if (assembly.fragments[dh.fragIdx] === null) {
      assembly.fragments[dh.fragIdx] = fragData;
      assembly.received++;
    }

    // All fragments received?
    if (assembly.received === dh.fragTotal) {
      const payload = new Uint8Array(th.payloadLen);
      let offset = 0;
      for (const frag of assembly.fragments) {
        if (frag) {
          payload.set(frag, offset);
          offset += frag.byteLength;
        }
      }

      if (th.codec === Codec.Raw && payload.byteLength > 0) {
        // Infer canvas size from highest tile coordinates seen.
        if (dh.frameSeq !== latestFrameSeq) {
          latestFrameSeq = dh.frameSeq;
        }
        renderer.drawRawTile(th.tileX, th.tileY, payload);
      }

      assemblyMap.delete(key);
      framesRendered++;

      if (framesRendered === 1) {
        statusEl.textContent = 'Receiving frames';
        log(`First tile rendered: (${th.tileX}, ${th.tileY})`);
      }
    }

    // Evict stale assemblies (frames more than 2 behind).
    if (dh.frameSeq > 2) {
      for (const [k] of assemblyMap) {
        const seq = parseInt(k.split(':')[0]);
        if (seq < dh.frameSeq - 2) {
          assemblyMap.delete(k);
        }
      }
    }
  }
}

function hexToBuffer(hex: string): ArrayBuffer {
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < hex.length; i += 2) {
    bytes[i / 2] = parseInt(hex.substr(i, 2), 16);
  }
  return bytes.buffer;
}

main().catch((e) => {
  log(`Error: ${e.message}`);
  statusEl.textContent = `Error: ${e.message}`;
});
```

//! DMA-BUF pixel readback.
//!
//! Two implementations:
//! - `readback_dmabuf()`: simple mmap (fallback, used in tests without GPU)
//! - `VulkanReadback`: Vulkan DMA-BUF import with staging buffer copy
//!
//! The xdaemon uses `VulkanReadback` when a GPU is available, falling back
//! to `readback_dmabuf()` if Vulkan initialization fails.

use std::ffi::CStr;
use std::io;
use std::sync::Arc;

use ash::vk;

/// Simple mmap readback (Task 5 implementation, kept as fallback).

    _width: u32,
    height: u32,
    stride: u32,

/// Vulkan-based DMA-BUF pixel readback.
///
/// Holds a Vulkan device with DMA-BUF import extensions enabled.
/// In M2 this struct will be extended with compute shader pipelines
/// for SAD tile diff.
pub struct VulkanReadback {
    entry: Arc<ash::Entry>,
    instance: ash::Instance,
    physical_device: vk::PhysicalDevice,
    device: ash::Device,
    queue: vk::Queue,
    queue_family_index: u32,
    command_pool: vk::CommandPool,
    device_name: String,
}

impl VulkanReadback {
    /// Create a Vulkan device with DMA-BUF import extensions.
    ///
    /// Required extensions:
    /// - VK_KHR_external_memory_fd
    /// - VK_EXT_external_memory_dma_buf
    /// - VK_EXT_image_drm_format_modifier (for format queries)
    pub fn new() -> Result<Self, Box<dyn std::error::Error + Send + Sync>> {
        let entry = unsafe { ash::Entry::load()? };

        // Create instance (no validation layers in release)
        let app_info = vk::ApplicationInfo::default()
            .application_name(c"ghostframe")
            .api_version(vk::make_api_version(0, 1, 3, 0));

        let instance_info = vk::InstanceCreateInfo::default()
            .application_info(&app_info);

        let instance = unsafe { entry.create_instance(&instance_info, None)? };

        // Pick first discrete or integrated GPU
        let physical_devices = unsafe { instance.enumerate_physical_devices()? };
        let physical_device = physical_devices
            .into_iter()
            .next()
            .ok_or("no Vulkan physical device found")?;

        let props = unsafe { instance.get_physical_device_properties(physical_device) };
        let device_name = unsafe {
            CStr::from_ptr(props.device_name.as_ptr())
                .to_string_lossy()
                .into_owned()
        };

        // Find a queue family with transfer capability
        let queue_families =
            unsafe { instance.get_physical_device_queue_family_properties(physical_device) };
        let queue_family_index = queue_families
            .iter()
            .position(|qf| qf.queue_flags.contains(vk::QueueFlags::TRANSFER))
            .ok_or("no transfer queue family")? as u32;

        let queue_priority = [1.0f32];
        let queue_info = vk::DeviceQueueCreateInfo::default()
            .queue_family_index(queue_family_index)
            .queue_priorities(&queue_priority);

        // Enable DMA-BUF import extensions
        let device_extensions = [
            ash::khr::external_memory_fd::NAME.as_ptr(),
            ash::ext::external_memory_dma_buf::NAME.as_ptr(),
        ];

        let device_info = vk::DeviceCreateInfo::default()
            .queue_create_infos(std::slice::from_ref(&queue_info))
            .enabled_extension_names(&device_extensions);

        let device = unsafe { instance.create_device(physical_device, &device_info, None)? };
        let queue = unsafe { device.get_device_queue(queue_family_index, 0) };

        let pool_info = vk::CommandPoolCreateInfo::default()
            .queue_family_index(queue_family_index)
            .flags(vk::CommandPoolCreateFlags::RESET_COMMAND_BUFFER);
        let command_pool = unsafe { device.create_command_pool(&pool_info, None)? };

        Ok(Self {
            entry: Arc::new(entry),
            instance,
            physical_device,
            device,
            queue,
            queue_family_index,
            command_pool,
            device_name,
        })
    }

    pub fn device_name(&self) -> &str {
        &self.device_name
    }

    /// Import a DMA-BUF fd and read pixels into a Vec.
    ///
    /// Pipeline:
    /// 1. Import DMA-BUF fd as VkDeviceMemory (VK_EXT_external_memory_dma_buf)
    /// 2. Create VkImage backed by that memory
    /// 3. Allocate host-visible staging buffer
    /// 4. vkCmdCopyImageToBuffer
    /// 5. Map staging buffer, copy pixels out
    pub fn readback(
        &self,
        dmabuf_fd: std::os::unix::io::RawFd,
        width: u32,
        height: u32,
        stride: u32,
    ) -> Result<Vec<u8>, Box<dyn std::error::Error + Send + Sync>> {
        let size = (stride * height) as u64;

        // --- 1. Import DMA-BUF fd as VkDeviceMemory ---
        let mut import_info = vk::ImportMemoryFdInfoKHR::default()
            .handle_type(vk::ExternalMemoryHandleTypeFlags::DMA_BUF_EXT)
            .fd(dmabuf_fd);

        let mem_alloc_info = vk::MemoryAllocateInfo::default()
            .allocation_size(size)
            .memory_type_index(self.find_memory_type(
                vk::MemoryPropertyFlags::DEVICE_LOCAL,
            )?)
            .push_next(&mut import_info);

        let imported_memory = unsafe { self.device.allocate_memory(&mem_alloc_info, None)? };

        // --- 2. Create VkImage backed by imported memory ---
        let image_info = vk::ImageCreateInfo::default()
            .image_type(vk::ImageType::TYPE_2D)
            .format(vk::Format::B8G8R8A8_UNORM)
            .extent(vk::Extent3D { width, height, depth: 1 })
            .mip_levels(1)
            .array_layers(1)
            .samples(vk::SampleCountFlags::TYPE_1)
            .tiling(vk::ImageTiling::LINEAR)
            .usage(vk::ImageUsageFlags::TRANSFER_SRC)
            .sharing_mode(vk::SharingMode::EXCLUSIVE);

        let image = unsafe { self.device.create_image(&image_info, None)? };
        unsafe { self.device.bind_image_memory(image, imported_memory, 0)? };

        // --- 3. Allocate host-visible staging buffer ---
        let buffer_info = vk::BufferCreateInfo::default()
            .size(size)
            .usage(vk::BufferUsageFlags::TRANSFER_DST)
            .sharing_mode(vk::SharingMode::EXCLUSIVE);

        let staging_buffer = unsafe { self.device.create_buffer(&buffer_info, None)? };
        let buf_mem_reqs = unsafe { self.device.get_buffer_memory_requirements(staging_buffer) };

        let staging_mem_info = vk::MemoryAllocateInfo::default()
            .allocation_size(buf_mem_reqs.size)
            .memory_type_index(self.find_memory_type(
                vk::MemoryPropertyFlags::HOST_VISIBLE | vk::MemoryPropertyFlags::HOST_COHERENT,
            )?);

        let staging_memory = unsafe { self.device.allocate_memory(&staging_mem_info, None)? };
        unsafe { self.device.bind_buffer_memory(staging_buffer, staging_memory, 0)? };

        // --- 4. Record + submit copy command ---
        let cmd_alloc_info = vk::CommandBufferAllocateInfo::default()
            .command_pool(self.command_pool)
            .level(vk::CommandBufferLevel::PRIMARY)
            .command_buffer_count(1);
        let cmd = unsafe { self.device.allocate_command_buffers(&cmd_alloc_info)? }[0];

        let begin_info = vk::CommandBufferBeginInfo::default()
            .flags(vk::CommandBufferUsageFlags::ONE_TIME_SUBMIT);
        unsafe { self.device.begin_command_buffer(cmd, &begin_info)? };

        // Transition image layout for transfer
        let barrier = vk::ImageMemoryBarrier::default()
            .old_layout(vk::ImageLayout::UNDEFINED)
            .new_layout(vk::ImageLayout::TRANSFER_SRC_OPTIMAL)
            .image(image)
            .subresource_range(vk::ImageSubresourceRange {
                aspect_mask: vk::ImageAspectFlags::COLOR,
                base_mip_level: 0,
                level_count: 1,
                base_array_layer: 0,
                layer_count: 1,
            });

        unsafe {
            self.device.cmd_pipeline_barrier(
                cmd,
                vk::PipelineStageFlags::TOP_OF_PIPE,
                vk::PipelineStageFlags::TRANSFER,
                vk::DependencyFlags::empty(),
                &[], &[], &[barrier],
            );
        }

        let region = vk::BufferImageCopy::default()
            .buffer_offset(0)
            .buffer_row_length(stride / 4) // pixels, not bytes
            .buffer_image_height(height)
            .image_subresource(vk::ImageSubresourceLayers {
                aspect_mask: vk::ImageAspectFlags::COLOR,
                mip_level: 0,
                base_array_layer: 0,
                layer_count: 1,
            })
            .image_extent(vk::Extent3D { width, height, depth: 1 });

        unsafe {
            self.device.cmd_copy_image_to_buffer(
                cmd,
                image,
                vk::ImageLayout::TRANSFER_SRC_OPTIMAL,
                staging_buffer,
                &[region],
            );
            self.device.end_command_buffer(cmd)?;
        }

        let submit_info = vk::SubmitInfo::default()
            .command_buffers(std::slice::from_ref(&cmd));
        unsafe {
            self.device.queue_submit(self.queue, &[submit_info], vk::Fence::null())?;
            self.device.queue_wait_idle(self.queue)?;
        }

        // --- 5. Map staging buffer, copy pixels ---
        let ptr = unsafe {
            self.device.map_memory(staging_memory, 0, size, vk::MemoryMapFlags::empty())?
        };
        let mut pixels = vec![0u8; size as usize];
        unsafe {
            std::ptr::copy_nonoverlapping(ptr as *const u8, pixels.as_mut_ptr(), size as usize);
            self.device.unmap_memory(staging_memory);
        }

        // --- Cleanup ---
        unsafe {
            self.device.free_command_buffers(self.command_pool, &[cmd]);
            self.device.destroy_buffer(staging_buffer, None);
            self.device.free_memory(staging_memory, None);
            self.device.destroy_image(image, None);
            // Note: don't free imported_memory -- the fd owns the backing store.
            // Actually we must free it to release the Vulkan handle, but the
            // underlying DMA-BUF stays alive as long as the fd is open.
            self.device.free_memory(imported_memory, None);
        }

        Ok(pixels)
    }

    fn find_memory_type(
        &self,
        flags: vk::MemoryPropertyFlags,
    ) -> Result<u32, Box<dyn std::error::Error + Send + Sync>> {
        let mem_props = unsafe {
            self.instance
                .get_physical_device_memory_properties(self.physical_device)
        };
        for i in 0..mem_props.memory_type_count {
            if mem_props.memory_types[i as usize]
                .property_flags
                .contains(flags)
            {
                return Ok(i);
            }
        }
        Err(format!("no memory type with flags {flags:?}").into())
    }
}

impl Drop for VulkanReadback {
    fn drop(&mut self) {
        unsafe {
            self.device.destroy_command_pool(self.command_pool, None);
            self.device.destroy_device(None);
            self.instance.destroy_instance(None);
        }
    }
}

## Implementation Notes

### DRM Capture Challenges

The DRM capture path (`drmModeGetFB2` -> `drmPrimeHandleToFD`) requires:
1. GPU hardware accessible at `/dev/dri/card0`
2. An active CRTC with a framebuffer (an X server or compositor must be running)
3. CAP_SYS_ADMIN or DRM master permissions

In the test container, we run as root with `--privileged` to satisfy these requirements. The X dummy driver may not expose DRM framebuffers; if so, the container needs the host GPU via `--device /dev/dri` and appropriate mesa drivers.

**Fallback if DRM capture proves problematic in containers:** Use `x11rb`'s `GetImage` request (XGetImage equivalent) to capture pixels from the X root window. This works with any X server including Xvfb but bypasses the DRM/DMA-BUF path. This is acceptable for M1 since M1's goal is proving the transport pipeline, not the GPU capture path. DRM capture becomes critical in M2 for zero-copy Vulkan compute.

### Canvas Size Negotiation

For M1, the canvas size is hardcoded to 640x480 (matching the test pattern). The web client should set the canvas size based on the first frame's tile grid dimensions. A proper display negotiation protocol (communicating resolution over a QUIC stream) is deferred to M4.

The web client can infer the canvas size from the highest (tile_x, tile_y) seen in the first complete frame: `width = (max_tile_x + 1) * 32`, `height = (max_tile_y + 1) * 32`.

### Dependency Versions

The implementation agent should verify current crate versions via `context7` or crates.io:
- `drm` crate: verify API for `resource_handles()`, `get_framebuffer2()`, `buffer_to_prime_fd()`
- `x11rb`: verify `create_window`, `poly_fill_rectangle` API
- `nix`: verify `memfd_create`, `mmap` API
- `clap`: verify derive API

### Build Order

Tasks 1-4 can be developed and tested without GPU hardware (pure logic + unit tests). Tasks 5-7 require GPU or can use the XGetImage fallback. Task 9 (web client) is independent of server-side tasks. Task 10 requires everything. Task 11 (Vulkan) runs after Task 10 passes, using the E2E test as a regression gate.

Recommended build sequence for maximum parallelism:
- **Parallel track A**: Tasks 1 -> 2 -> 3 -> 4 (protocol -> tile -> server -> io_bridge)
- **Parallel track B**: Task 6 (test pattern app, independent)
- **Parallel track C**: Task 9 (web client, independent once protocol format is defined)
- **Sequential**: Task 5 (capture/mmap) -> Task 7 (xdaemon) -> Task 8 (FFI) -> Task 10 (E2E) -> Task 11 (Vulkan)
