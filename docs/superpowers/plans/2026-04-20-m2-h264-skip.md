# M2: H.264 + Skip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hardware-encode H.264 tiles via VA-API, decode in browser via WebCodecs, and skip sending unchanged tiles — proving the zero-copy DMA-BUF encode pipeline and bandwidth savings from skip detection.

**Architecture:** The server's `process_frame()` gains per-tile dirty detection by comparing the current tile against the previous frame's tile (byte-level equality for now, GPU SAD in a future pass). Dirty tiles are H.264-encoded via `ffmpeg` C API (libavcodec VA-API). The web client uses WebCodecs `VideoDecoder` for H.264 and persists skip tiles from the last-rendered frame. XDamage is added as an optional optimization that narrows the set of tiles to check.

**Tech Stack:** `ffmpeg-next` (Rust libavcodec bindings), VA-API hardware encoder, WebCodecs API (browser), XDamage X11 extension (`x11rb`)

```rust
/// Tracks per-tile content to detect changes between frames.
///
/// Stores the previous frame's tile data and compares byte-by-byte.
/// Returns the list of (tile_x, tile_y) coordinates that changed.
pub struct DirtyTracker {
    cols: u32,
    rows: u32,
    /// Previous tile data, indexed as [row * cols + col], each TILE_BYTES long.
    prev_tiles: Vec<Vec<u8>>,
}

impl DirtyTracker {
    pub fn new(cols: u32, rows: u32) -> Self {
        let count = (cols * rows) as usize;
        Self {
            cols,
            rows,
            prev_tiles: vec![Vec::new(); count],
        }
    }

    /// Resize tracker for a new grid. Clears all state (next frame = all dirty).
    pub fn resize(&mut self, cols: u32, rows: u32) {
        self.cols = cols;
        self.rows = rows;
        self.prev_tiles = vec![Vec::new(); (cols * rows) as usize];
    }

    /// Compare all tiles against previous frame, returning dirty coordinates.
    pub fn update(&mut self, pixels: &[u8], stride: u32, width: u32, height: u32) -> Vec<(u32, u32)> {
        let grid = TileGrid::new(width, height);
        if grid.cols != self.cols || grid.rows != self.rows {
            self.resize(grid.cols, grid.rows);
        }
        let mut dirty = Vec::new();
        for (tile_x, tile_y) in grid.iter_coords() {
            let idx = (tile_y * self.cols + tile_x) as usize;
            let current = grid.extract_tile(pixels, stride, tile_x, tile_y);
            if self.prev_tiles[idx] != current {
                self.prev_tiles[idx] = current;
                dirty.push((tile_x, tile_y));
            }
        }
        dirty
    }

    /// Like `update`, but only check tiles overlapping the given hint coordinates.
    /// Tiles not in the hints list are assumed unchanged (skip without comparison).
    pub fn update_with_hints(
        &mut self,
        pixels: &[u8],
        stride: u32,
        width: u32,
        height: u32,
        hints: &[(u32, u32)],
    ) -> Vec<(u32, u32)> {
        let grid = TileGrid::new(width, height);
        if grid.cols != self.cols || grid.rows != self.rows {
            self.resize(grid.cols, grid.rows);
        }
        let mut dirty = Vec::new();
        for &(tile_x, tile_y) in hints {
            if tile_x >= self.cols || tile_y >= self.rows {
                continue;
            }
            let idx = (tile_y * self.cols + tile_x) as usize;
            let current = grid.extract_tile(pixels, stride, tile_x, tile_y);
            if self.prev_tiles[idx] != current {
                self.prev_tiles[idx] = current;
                dirty.push((tile_x, tile_y));
            }
        }
        dirty
    }
}
```

//! H.264 encoding via VA-API through libavcodec.
//!
//! Each encoder instance handles one tile position (32×32 BGRA).
//! The encoder maintains inter-frame state so P-frames reference previous tiles.

use ffmpeg_next as ffmpeg;
use ffmpeg::codec;
use ffmpeg::format::Pixel;
use ffmpeg::software::scaling;

use super::EncodedTile;
use crate::transport::protocol::Codec;

/// H.264 VA-API encoder for a single 32×32 tile stream.
pub struct H264VaapiEncoder {
    encoder: ffmpeg::encoder::Video,
    scaler: scaling::Context,
    frame_count: u64,
    pts: i64,
}

impl H264VaapiEncoder {
    /// Create a new encoder. Uses VA-API hardware acceleration if available,
    /// falls back to libx264 software encoder.
    pub fn new() -> Result<Self, ffmpeg::Error> {
        ffmpeg::init()?;

        // Try h264_vaapi first, fall back to libx264
        let codec = ffmpeg::encoder::find_by_name("h264_vaapi")
            .or_else(|| ffmpeg::encoder::find_by_name("libx264"))
            .ok_or(ffmpeg::Error::EncoderNotFound)?;

        let mut context = codec::context::Context::new_with_codec(codec);
        let mut encoder = context.encoder().video()?;

        encoder.set_width(32);
        encoder.set_height(32);
        encoder.set_format(Pixel::NV12);
        encoder.set_time_base(ffmpeg::Rational::new(1, 30));
        encoder.set_frame_rate(Some(ffmpeg::Rational::new(30, 1)));

        // Low-latency settings
        unsafe {
            use std::ffi::CString;
            let key = CString::new("preset").unwrap();
            let val = CString::new("ultrafast").unwrap();
            ffmpeg::ffi::av_opt_set(
                encoder.as_mut_ptr() as *mut _,
                key.as_ptr(),
                val.as_ptr(),
                0,
            );
            let key = CString::new("tune").unwrap();
            let val = CString::new("zerolatency").unwrap();
            ffmpeg::ffi::av_opt_set(
                encoder.as_mut_ptr() as *mut _,
                key.as_ptr(),
                val.as_ptr(),
                0,
            );
        }

        let encoder = encoder.open_as(codec)?;

        let scaler = scaling::Context::get(
            Pixel::BGRA,
            32,
            32,
            Pixel::NV12,
            32,
            32,
            scaling::Flags::FAST_BILINEAR,
        )?;

        Ok(Self {
            encoder,
            scaler,
            frame_count: 0,
            pts: 0,
        })
    }

    /// Encode a 32×32 BGRA tile (4096 bytes) into H.264 NAL units.
    ///
    /// Returns `None` if the encoder buffered the frame without producing output
    /// (should not happen with zerolatency, but handle gracefully).
    pub fn encode(&mut self, bgra_tile: &[u8]) -> Result<Option<EncodedTile>, ffmpeg::Error> {
        assert_eq!(bgra_tile.len(), 32 * 32 * 4);

        // Create input frame (BGRA)
        let mut src_frame = ffmpeg::frame::Video::new(Pixel::BGRA, 32, 32);
        src_frame.data_mut(0)[..bgra_tile.len()].copy_from_slice(bgra_tile);

        // Convert BGRA → NV12
        let mut dst_frame = ffmpeg::frame::Video::new(Pixel::NV12, 32, 32);
        self.scaler.run(&src_frame, &mut dst_frame)?;

        dst_frame.set_pts(Some(self.pts));
        self.pts += 1;
        self.frame_count += 1;

        // Send frame to encoder
        self.encoder.send_frame(&dst_frame)?;

        // Receive encoded packet
        let mut packet = ffmpeg::Packet::empty();
        match self.encoder.receive_packet(&mut packet) {
            Ok(()) => {
                let data = packet.data().unwrap_or(&[]).to_vec();
                Ok(Some(EncodedTile {
                    codec: Codec::H264,
                    payload: data,
                }))
            }
            Err(ffmpeg::Error::Other { errno: ffmpeg::ffi::EAGAIN }) => Ok(None),
            Err(e) => Err(e),
        }
    }
}

```rust
fn process_frame(&mut self, frame: FrameSubmission) {
    let grid = TileGrid::new(frame.width, frame.height);
    self.frame_seq = self.frame_seq.wrapping_add(1);
    let seq = self.frame_seq;

    // Determine dirty tiles
    let dirty_tiles = match &frame.damage_tiles {
        Some(hints) => self.dirty_tracker.update_with_hints(
            &frame.pixels, frame.stride, frame.width, frame.height, hints,
        ),
        None => self.dirty_tracker.update(
            &frame.pixels, frame.stride, frame.width, frame.height,
        ),
    };

    if dirty_tiles.is_empty() {
        return; // Nothing changed — no datagrams to send
    }

    // Calculate max fragment payload (same as before)
    let max_frag = {
        let mut min_size: Option<usize> = None;
        for (handle, wt) in &self.wt_sessions {
            if !wt.is_connected() {
                continue;
            }
            if let Some(conn) = self.server.connections.get_mut(handle) {
                if let Some(sz) = conn.datagrams().max_size() {
                    let usable = max_fragment_payload(
                        sz.saturating_sub(Self::WT_VARINT_OVERHEAD),
                    );
                    min_size = Some(match min_size {
                        Some(prev) => prev.min(usable),
                        None => usable,
                    });
                }
            }
        }
        match min_size {
            Some(0) | None => return,
            Some(sz) => sz,
        }
    };

    // Encode and send only dirty tiles
    for (tile_x, tile_y) in &dirty_tiles {
        let tile_data = grid.extract_tile(&frame.pixels, frame.stride, *tile_x, *tile_y);

        let (codec, payload) = if self.h264_available {
            let encoder = self.encoders
                .entry((*tile_x, *tile_y))
                .or_insert_with(|| H264VaapiEncoder::new().unwrap());
            match encoder.encode(&tile_data) {
                Ok(Some(encoded)) => (encoded.codec, encoded.payload),
                Ok(None) => (Codec::Raw, tile_data),  // Encoder buffered — send raw
                Err(e) => {
                    tracing::warn!(tile_x, tile_y, error = %e, "H.264 encode failed, sending raw");
                    (Codec::Raw, tile_data)
                }
            }
        } else {
            (Codec::Raw, tile_data)
        };

        let datagrams = fragment_tile(
            seq,
            *tile_x as u8,
            *tile_y as u8,
            codec,
            &payload,
            frame.timestamp_us,
            max_frag,
        );

        for dg in &datagrams {
            for (handle, wt) in &mut self.wt_sessions {
                if !wt.is_connected() {
                    continue;
                }
                if let Some(conn) = self.server.connections.get_mut(handle) {
                    if let Err(e) = wt.send_datagram(conn, dg) {
                        tracing::trace!(?handle, tile_x, tile_y, error = ?e,
                            "datagram send failed (congestion/buffer full)");
                    }
                }
            }
        }
    }
}

/**
 * Per-tile H.264 decoder using WebCodecs VideoDecoder.
 * Each tile position gets its own decoder instance to maintain inter-frame state.
 */
export class H264TileDecoder {
  private decoder: VideoDecoder;
  private latestFrame: VideoFrame | null = null;
  private ready: boolean = false;

  constructor(private onFrame: (frame: VideoFrame) => void) {
    this.decoder = new VideoDecoder({
      output: (frame: VideoFrame) => {
        if (this.latestFrame) {
          this.latestFrame.close();
        }
        this.latestFrame = frame;
        this.onFrame(frame);
      },
      error: (e: DOMException) => {
        console.error('H264 decode error:', e.message);
      },
    });

    this.decoder.configure({
      codec: 'avc1.42001e', // Baseline profile, level 3.0
      codedWidth: 32,
      codedHeight: 32,
      optimizeForLatency: true,
    });
    this.ready = true;
  }

  decode(nalData: Uint8Array) {
    if (!this.ready || this.decoder.state === 'closed') return;

    // Detect keyframe: check NAL unit type (first byte after start code)
    const isKey = this.isKeyframe(nalData);

    const chunk = new EncodedVideoChunk({
      type: isKey ? 'key' : 'delta',
      timestamp: 0, // We don't use timestamp-based scheduling
      data: nalData,
    });

    this.decoder.decode(chunk);
  }

  private isKeyframe(data: Uint8Array): boolean {
    // Scan for NAL start code (0x00 0x00 0x01 or 0x00 0x00 0x00 0x01)
    // then check NAL type: 5 = IDR slice (keyframe)
    for (let i = 0; i < data.length - 4; i++) {
      if (data[i] === 0 && data[i + 1] === 0) {
        let nalStart: number;
        if (data[i + 2] === 1) {
          nalStart = i + 3;
        } else if (data[i + 2] === 0 && data[i + 3] === 1) {
          nalStart = i + 4;
        } else {
          continue;
        }
        if (nalStart < data.length) {
          const nalType = data[nalStart] & 0x1f;
          if (nalType === 5) return true; // IDR
          if (nalType === 7) return true; // SPS (precedes keyframe)
        }
      }
    }
    return false;
  }

  close() {
    if (this.decoder.state !== 'closed') {
      this.decoder.close();
    }
    if (this.latestFrame) {
      this.latestFrame.close();
      this.latestFrame = null;
    }
  }
}
```

```rust
//! XDamage integration: monitors root window damage events and maps
//! damaged pixel rectangles to tile grid coordinates.

use x11rb::connection::Connection;
use x11rb::protocol::damage::{self, ConnectionExt as DamageExt};
use x11rb::protocol::xproto::ConnectionExt;
use x11rb::rust_connection::RustConnection;

use ghostframe_lib::tile::TILE_SIZE;

/// Tracks X11 damage events on the root window.
pub struct XDamageMonitor {
    conn: RustConnection,
    damage_id: u32,
    screen_width: u32,
    screen_height: u32,
    damage_ext_opcode: u8,
}

impl XDamageMonitor {
    /// Initialize XDamage on the root window.
    /// Returns `None` if the XDamage extension is not available.
    pub fn new() -> Option<Self> {
        let (conn, screen_num) = RustConnection::connect(None).ok()?;

        // Query damage extension
        let damage_ext = conn.query_extension(b"DAMAGE").ok()?.reply().ok()?;
        if !damage_ext.present {
            return None;
        }
        let damage_ext_opcode = damage_ext.first_event;

        // Initialize damage extension
        conn.damage_query_version(1, 1).ok()?.reply().ok()?;

        let screen = &conn.setup().roots[screen_num];
        let screen_width = screen.width_in_pixels as u32;
        let screen_height = screen.height_in_pixels as u32;
        let root = screen.root;

        // Create damage object on root window, reporting RawRectangles
        let damage_id = conn.generate_id().ok()?;
        conn.damage_create(
            damage_id,
            root,
            damage::ReportLevel::RAW_RECTANGLES,
        ).ok()?;

        conn.flush().ok()?;

        Some(Self {
            conn,
            damage_id,
            screen_width,
            screen_height,
            damage_ext_opcode,
        })
    }

    /// Drain all pending damage events and return the set of dirty tile coordinates.
    /// Non-blocking: returns empty vec if no damage events are pending.
    pub fn drain_damage(&self) -> Vec<(u32, u32)> {
        let mut tile_set = std::collections::HashSet::new();

        // Subtract damage (acknowledges it and gets the region)
        // Use a dummy region — we read from events, not the region
        let _ = self.conn.damage_subtract(self.damage_id, 0u32, 0u32);
        let _ = self.conn.flush();

        // Poll for damage notify events
        loop {
            match self.conn.poll_for_event().ok().flatten() {
                Some(event) => {
                    let event_type = event.response_type() & 0x7f;
                    if event_type == self.damage_ext_opcode {
                        // Parse DamageNotify: geometry at bytes 8-15
                        let raw = event.raw_bytes();
                        if raw.len() >= 28 {
                            let x = u16::from_ne_bytes([raw[12], raw[13]]) as u32;
                            let y = u16::from_ne_bytes([raw[14], raw[15]]) as u32;
                            let w = u16::from_ne_bytes([raw[16], raw[17]]) as u32;
                            let h = u16::from_ne_bytes([raw[18], raw[19]]) as u32;
                            // Map pixel rect to tile coords
                            let tx_start = x / TILE_SIZE;
                            let ty_start = y / TILE_SIZE;
                            let tx_end = (x + w).div_ceil(TILE_SIZE);
                            let ty_end = (y + h).div_ceil(TILE_SIZE);
                            for ty in ty_start..ty_end {
                                for tx in tx_start..tx_end {
                                    tile_set.insert((tx, ty));
                                }
                            }
                        }
                    }
                }
                None => break,
            }
        }

        tile_set.into_iter().collect()
    }

    pub fn screen_width(&self) -> u32 {
        self.screen_width
    }

    pub fn screen_height(&self) -> u32 {
        self.screen_height
    }
}

impl Drop for XDamageMonitor {
    fn drop(&mut self) {
        let _ = self.conn.damage_destroy(self.damage_id);
    }
}
```
