# BC1 Removal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the BC1 codec variant from the codebase end-to-end. BC1 was never implemented and the M3.5b bench data argued for dropping it (`docs/specs/m3-codec-bench-results.md` §7).

**Architecture:** Five layered commits, each independently buildable and green. Order: (1) make CDF53 always-on (remove gate); (2) drop HELLO `supports_cdf53` capability bit; (3) rewire classifier Rules 3 & 5 fallback from `Bc1` to `Cdf53` and prune escalation source-set; (4) delete `CodecState::Bc1` and `CostModel::bc1_us` (compiler-driven cleanup); (5) compact wire enum `Codec::{Solid 4→3, Raw 5→4, Cdf53 6→5}` + web client + bench Section 7.

**Tech Stack:** Rust (workspace: `ghostframe-lib`, `ghostframe-bench`, `ghostframe-e2e`), TypeScript (`ghostframe-web-client`), WGSL (no BC1 references; not touched).

**Design doc:** `docs/superpowers/specs/2026-06-05-bc1-removal-design.md`

**Branch suggestion:** `refactor/bc1-removal`
