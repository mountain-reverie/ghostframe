# M3.7 — Bench Tuning Investments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the bench-side infrastructure that produces empirical signal to retune the 3 M3.6 policy constants (`REFINEMENT_BIAS_PER_TILE_US`, `HEADROOM_MIN_BYTES_PER_US`, `LOSS_OVERRIDE_THRESHOLD`), with retune commits backed by data instead of judgment.

**Architecture:** Two sub-phases mirroring M3.6 cadence. M3.7a adds PixelPerfect + decode_error metrics to the harness, a `--subtle-drift` mode to `ghostframe-test-pattern` so pure scenes generate dirty events, and cfg-gated env-var overrides for the 2 constants tunable without realistic-cwnd. Two new bench modes (`--bias-sweep`, `--loss-axis`) sweep them across 4-6 values; closes with a retune commit citing Tables 11+12. M3.7b adds `tc qdisc` shaping inside the test-server container so QUIC actually sees realistic cwnd shrinkage; env-var override for the 3rd constant and two more bench modes (`--shaping-matrix`, `--headroom-sweep`); closes with a retune commit citing Tables 13+14.

**Tech Stack:** Rust (`ghostframe-lib::tile::classifier`, `ghostframe-e2e::harness`, `ghostframe-test-pattern`, `ghostframe-bench`), existing `tracing::info!` + JSON subscriber telemetry pipeline, existing `testcontainers` + `chromiumoxide` e2e harness, `iproute2` (`tc`) for kernel-level network shaping inside the privileged test-server container.

**Spec:** `docs/superpowers/specs/2026-06-03-m3.7-bench-tuning-investments-design.md`.

```rust
//! M3.7a subtle-drift mode: paint the configured `tile_pattern` class to
//! the DRM scanout, then every `drift_ms` milliseconds shift the bitmap
//! by 1 pixel along the X axis (wrapping). Generates dirty events for
//! the classifier without changing the perceptual content of pure scenes.

use std::time::Duration;

use crate::tile_pattern;

pub fn run(
    card_path: &str,
    class_name: &str,
    drift_ms: u64,
) -> Result<(), Box<dyn std::error::Error>> {
    if drift_ms == 0 {
        // 0 ⇒ disable drift, fall through to the existing static behavior.
        return tile_pattern::run(card_path, class_name);
    }

    let mut scanout = tile_pattern::setup_dumb_scanout(card_path)?;
    let width = scanout.mode_w as usize;
    let height = scanout.mode_h as usize;
    let pitch = scanout.pitch as usize;
    eprintln!(
        "subtle-drift: scanout {}x{} active — class {:?}, drift every {}ms",
        width, height, class_name, drift_ms
    );

    // Initial paint.
    {
        let mut map = scanout
            .card
            .map_dumb_buffer(&mut scanout.db)
            .map_err(|e| format!("map_dumb_buffer: {e}"))?;
        let bytes = map.as_mut();
        tile_pattern::fill_with_tile_pattern(class_name, scanout.mode_w, scanout.mode_h, pitch, bytes);
        tile_pattern::msync_buffer(bytes);
    }

    // Drift loop: shift bytes left by 4 (one BGRX pixel) per row, wrapping
    // the leftmost pixel to the right edge. msync each frame.
    loop {
        std::thread::sleep(Duration::from_millis(drift_ms));
        let mut map = scanout
            .card
            .map_dumb_buffer(&mut scanout.db)
            .map_err(|e| format!("map_dumb_buffer: {e}"))?;
        let bytes = map.as_mut();
        for row in 0..height {
            let start = row * pitch;
            let row_bytes = width * 4; // BGRX = 4 bytes per pixel
            if row_bytes < 4 || start + row_bytes > bytes.len() {
                break;
            }
            // Save leftmost pixel, shift, restore at right edge.
            let mut leftmost = [0u8; 4];
            leftmost.copy_from_slice(&bytes[start..start + 4]);
            bytes.copy_within(start + 4..start + row_bytes, start);
            bytes[start + row_bytes - 4..start + row_bytes].copy_from_slice(&leftmost);
        }
        tile_pattern::msync_buffer(bytes);
    }
}
```
